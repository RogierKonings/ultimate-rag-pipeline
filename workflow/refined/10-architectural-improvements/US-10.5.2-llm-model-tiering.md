# US-10.5.2: LLM Model Tiering

> **Initiative:** 5 - Cost-Aware Retrieval & Model Tiering
> **Priority:** P1
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Select LLM models based on query complexity and tenant tier to reduce inference costs while maintaining quality.

## User Story

**As a** platform operator
**I want** to use smaller models for simple queries
**So that** I can reduce inference costs

## Acceptance Criteria

- [ ] Router selects model based on QueryIntent and tenant tier
- [ ] Default: smaller model (Qwen2.5-7B or Llama-3.1-8B)
- [ ] Premium + complex queries: larger model (Llama-70B)
- [ ] Model selection logged per request
- [ ] Metrics: `llm_requests_by_model{model}`
- [ ] Fallback model on primary failure

## Technical Design

```python
# services/orchestrator/model_router.py

from enum import Enum

class ModelTier(str, Enum):
    SMALL = "small"   # 7-8B models
    MEDIUM = "medium" # 13-14B models
    LARGE = "large"   # 70B+ models

MODEL_CONFIGS = {
    ModelTier.SMALL: {
        "model_name": "qwen2.5-7b",
        "max_tokens": 2048,
        "cost_per_1k_tokens": 0.001,
    },
    ModelTier.MEDIUM: {
        "model_name": "llama-3.1-13b",
        "max_tokens": 4096,
        "cost_per_1k_tokens": 0.003,
    },
    ModelTier.LARGE: {
        "model_name": "llama-3.1-70b",
        "max_tokens": 8192,
        "cost_per_1k_tokens": 0.01,
    },
}

SELECTION_MATRIX = {
    # (tenant_tier, complexity) -> model_tier
    ("basic", "simple"): ModelTier.SMALL,
    ("basic", "complex"): ModelTier.SMALL,
    ("standard", "simple"): ModelTier.SMALL,
    ("standard", "complex"): ModelTier.MEDIUM,
    ("premium", "simple"): ModelTier.MEDIUM,
    ("premium", "complex"): ModelTier.LARGE,
}

class ModelRouter:
    """Routes requests to appropriate LLM model."""

    def select_model(
        self,
        tenant_tier: str,
        complexity: str,
        intent: str,
    ) -> dict:
        """Select model based on tenant and query characteristics."""
        key = (tenant_tier, complexity)
        model_tier = SELECTION_MATRIX.get(key, ModelTier.SMALL)

        # Override for specific intents
        if intent == "ANALYTICAL" and tenant_tier != "basic":
            model_tier = max(model_tier, ModelTier.MEDIUM)

        config = MODEL_CONFIGS[model_tier]
        return {
            "model": config["model_name"],
            "max_tokens": config["max_tokens"],
            "tier": model_tier.value,
        }

    async def get_fallback_model(self, failed_model: str) -> str:
        """Get fallback model if primary fails."""
        # Always fall back to small model
        return MODEL_CONFIGS[ModelTier.SMALL]["model_name"]
```
