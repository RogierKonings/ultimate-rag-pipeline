# US-10.2.2: Cross-Service Degradation Propagation

> **Initiative:** 2 - End-to-End Resilience & Adaptive Degradation
> **Priority:** P0
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Enable the orchestrator to receive and respond to degradation signals from the retrieval service, adjusting prompts and user expectations appropriately.

## Problem Statement

**Current state**: The orchestrator has its own resilience patterns in [resilience/](services/orchestrator/resilience/) but doesn't receive degradation information from retrieval:
- Orchestrator is unaware when retrieval operates in degraded mode
- User prompts don't reflect potential context limitations
- No end-to-end visibility of degradation cascade
- Streaming events don't indicate degradation

**Impact**:
- Users may be confused by lower quality results without explanation
- No ability to adjust LLM prompts based on retrieval quality
- Difficult to debug cross-service issues

## User Story

**As a** system developer
**I want** the orchestrator to adjust behavior based on retrieval degradation
**So that** user expectations are set appropriately

## Acceptance Criteria

### AC-1: Retrieval Response Enhancement
- [ ] Retrieval API response includes `degradation_level` field
- [ ] Response includes `components` status (which were used/skipped)
- [ ] Response includes `retrieval_mode` used
- [ ] JSON schema documented in OpenAPI

### AC-2: Orchestrator Degradation Handling
- [ ] Orchestrator parses degradation info from retrieval response
- [ ] Degradation state stored in `RAGState`
- [ ] Fallbacks tracked in `fallbacks_used` list

### AC-3: Prompt Adjustment
- [ ] System prompt adjusted when retrieval is degraded
- [ ] Includes contextual warning about potential incompleteness
- [ ] Different messages for different degradation modes

### AC-4: Streaming Events
- [ ] `metadata` streaming event includes degradation status
- [ ] `start` event indicates if operating in degraded mode
- [ ] Frontend can display warning to user

### AC-5: Response Metadata
- [ ] Final response includes `retrieval_mode_used`
- [ ] Includes `quality_indicator` field
- [ ] Includes `components_available` summary

### Retrieval Service Response Building

```python
# services/retrieval/search/hybrid.py

def _build_degradation_info(
    self,
    status: DegradationStatus,
) -> DegradationInfo:
    """Build degradation info for response."""
    # Determine overall level
    if status.mode == DegradationMode.HYBRID_FULL:
        level = "normal"
        message = None
    elif status.mode == DegradationMode.MINIMAL:
        level = "minimal"
        message = "Multiple retrieval components unavailable"
    else:
        level = "degraded"
        messages = {
            DegradationMode.SEMANTIC_ONLY: "Keyword search unavailable, using semantic search only",
            DegradationMode.KEYWORD_ONLY: "Semantic search unavailable, using keyword search only",
            DegradationMode.HYBRID_NO_RERANK: "Reranker unavailable, results may be less relevant",
        }
        message = messages.get(status.mode)

    components = [
        ComponentStatus(
            name="qdrant",
            available=status.qdrant_healthy,
            circuit_state=self.degradation.qdrant_breaker.state.value,
        ),
        ComponentStatus(
            name="opensearch",
            available=status.opensearch_healthy,
            circuit_state=self.degradation.opensearch_breaker.state.value,
        ),
        ComponentStatus(
            name="reranker",
            available=status.reranker_healthy,
            circuit_state=self.degradation.reranker_breaker.state.value,
        ),
    ]

    return DegradationInfo(
        level=level,
        mode=status.mode.value,
        components=components,
        message=message,
    )
```

### Retrieval Node Updates

```python
# services/orchestrator/workflow/nodes/retrieval.py

async def retrieval_node(state: RAGState) -> RAGState:
    """
    Retrieval node with degradation handling.

    Parses degradation info from retrieval response and updates state.
    """
    query = state["query"]
    user_context = state["user_context"]
    options = state.get("retrieval_options", {})

    # Call retrieval service
    response = await retrieval_client.search(
        query=query,
        user_context=user_context,
        options=options,
    )

    # Parse degradation info
    degradation = response.get("degradation", {})
    degradation_level = degradation.get("level", "normal")
    mode = degradation.get("mode", "hybrid_full")

    # Update state with results
    state["documents"] = response["results"]
    state["retrieval_quality"] = {
        "degradation_level": degradation_level,
        "mode": mode,
        "components_used": [
            c["name"] for c in degradation.get("components", [])
            if c.get("available")
        ],
        "components_skipped": [
            c["name"] for c in degradation.get("components", [])
            if not c.get("available")
        ],
    }

    # Track degradation as fallback
    if degradation_level != "normal":
        if "fallbacks_used" not in state:
            state["fallbacks_used"] = []
        state["fallbacks_used"].append(f"retrieval:{mode}")

    # Set context quality indicator
    if degradation_level == "minimal":
        state["context_quality"] = "minimal"
    elif degradation_level == "degraded":
        state["context_quality"] = "partial"
    else:
        state["context_quality"] = "full"

    logger.info(
        "retrieval_complete",
        result_count=len(response["results"]),
        degradation_level=degradation_level,
        mode=mode,
    )

    return state
```

### Prompt Building Adjustments

```python
# services/orchestrator/workflow/nodes/prompt_building.py

DEGRADATION_DISCLAIMERS = {
    "semantic_only": (
        "Note: The search results below were obtained using semantic similarity only. "
        "Keyword matching was unavailable, so some exact term matches may be missing."
    ),
    "keyword_only": (
        "Note: The search results below were obtained using keyword matching only. "
        "Semantic search was unavailable, so conceptually similar content may be missing."
    ),
    "hybrid_no_rerank": (
        "Note: Search results were not reranked for relevance. "
        "Results may not be in optimal order."
    ),
    "minimal": (
        "IMPORTANT: Search capabilities are significantly degraded. "
        "The context provided may be incomplete or less relevant than usual. "
        "Please indicate if the available information is insufficient to answer."
    ),
}

async def prompt_building_node(state: RAGState) -> RAGState:
    """
    Build prompt with degradation-aware adjustments.

    Adds contextual warnings when retrieval is degraded.
    """
    query = state["query"]
    documents = state.get("documents", [])
    retrieval_quality = state.get("retrieval_quality", {})

    # Build context from documents
    context = format_context(documents)

    # Add degradation disclaimer if needed
    degradation_level = retrieval_quality.get("degradation_level", "normal")
    mode = retrieval_quality.get("mode", "hybrid_full")

    disclaimer = ""
    if degradation_level != "normal" and mode in DEGRADATION_DISCLAIMERS:
        disclaimer = DEGRADATION_DISCLAIMERS[mode]

    # Build system prompt
    system_prompt = SYSTEM_PROMPT_TEMPLATE.render(
        context=context,
        degradation_disclaimer=disclaimer,
        context_quality=state.get("context_quality", "full"),
    )

    # Build messages
    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": query},
    ]

    state["messages"] = messages

    return state
```

### Streaming Events

```python
# services/orchestrator/streaming/events.py

from dataclasses import dataclass
from typing import Literal

@dataclass
class StreamMetadataEvent:
    """Metadata event with degradation info."""
    event: Literal["metadata"] = "metadata"
    request_id: str
    degradation: dict | None = None
    quality_indicator: str = "full"

class StreamManager:
    async def emit_metadata(
        self,
        request_id: str,
        state: RAGState,
    ) -> None:
        """Emit metadata event with degradation info."""
        retrieval_quality = state.get("retrieval_quality", {})

        event = StreamMetadataEvent(
            request_id=request_id,
            degradation={
                "level": retrieval_quality.get("degradation_level", "normal"),
                "mode": retrieval_quality.get("mode", "hybrid_full"),
                "message": self._get_user_friendly_message(retrieval_quality),
            } if retrieval_quality.get("degradation_level") != "normal" else None,
            quality_indicator=state.get("context_quality", "full"),
        )

        await self._send_event(event)

    def _get_user_friendly_message(self, quality: dict) -> str:
        """Get user-friendly degradation message."""
        mode = quality.get("mode", "")
        messages = {
            "semantic_only": "Using semantic search only",
            "keyword_only": "Using keyword search only",
            "hybrid_no_rerank": "Results may be less precisely ordered",
            "minimal": "Search capabilities limited",
        }
        return messages.get(mode, "")
```

    return QueryResponse(
        response=state["response"],

        metadata=QueryResponseMetadata(
            request_id=state["request_id"],

## Implementation Steps

1. **Update retrieval response schema**
   - Add `DegradationInfo` model
   - Update `SearchResponse` to include degradation
   - Document in OpenAPI spec

2. **Update retrieval service**
   - Build degradation info from manager
   - Include in all responses

3. **Update orchestrator state**
   - Add `retrieval_quality` field
   - Add `context_quality` field
   - Track in `fallbacks_used`

4. **Update retrieval node**
   - Parse degradation from response
   - Update state accordingly

5. **Update prompt building**
   - Add degradation disclaimers
   - Adjust system prompt template

6. **Update streaming**
   - Add metadata event with degradation
   - Include in start event

7. **Update response schema**
   - Add metadata to final response
   - Include components summary
