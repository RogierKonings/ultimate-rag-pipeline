# US-10.7.2: Database Security Enablement

> **Initiative:** 7 - Security & Production Hardening
> **Priority:** P0
> **Effort:** Small (1-2 days)
> **Status:** Draft

## Summary

Enable SSL/TLS connections and proper authentication for PostgreSQL, Redis, and OpenSearch in production environments.

## Problem Statement

**Current state**: Database connections lack security:
- PostgreSQL connections may be unencrypted
- Redis password might be weak or missing
- OpenSearch accessible without authentication
- Connection strings may contain credentials in logs

**Impact**:
- Data in transit exposed to interception
- Unauthorized database access possible
- Credential leakage in logs
- Compliance failures (PCI-DSS, HIPAA, SOC2)

## User Story

**As a** security engineer
**I want** encrypted and authenticated database connections
**So that** data is protected in transit and at rest

## Acceptance Criteria

### AC-1: PostgreSQL Security
- [ ] SSL/TLS enabled for all connections
- [ ] Certificate verification in production
- [ ] Connection pooler (PgBouncer) secured
- [ ] Password complexity enforced

### AC-2: Redis Security
- [ ] TLS enabled for connections
- [ ] Strong authentication required
- [ ] ACL-based command restrictions
- [ ] Sensitive commands disabled

### AC-3: OpenSearch Security
- [ ] HTTPS enabled
- [ ] Basic auth or certificate auth
- [ ] Role-based access control
- [ ] Audit logging enabled

### AC-4: Credential Management
- [ ] No credentials in connection strings
- [ ] Credentials from environment/secrets
- [ ] Connection strings sanitized in logs

```python
# services/shared/database/connection.py

import ssl
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
from sqlalchemy.orm import sessionmaker
import os

def create_ssl_context() -> ssl.SSLContext | None:
    """Create SSL context for PostgreSQL connection."""
    ssl_mode = os.getenv("POSTGRES_SSL_MODE", "prefer")

    if ssl_mode == "disable":
        return None

    ctx = ssl.create_default_context()

    if ssl_mode == "require":
        # Encrypt but don't verify certificate
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE

    elif ssl_mode == "verify-ca":
        # Verify certificate against CA
        ca_cert = os.getenv("POSTGRES_SSL_CA")
        if ca_cert:
            ctx.load_verify_locations(ca_cert)
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_REQUIRED

    elif ssl_mode == "verify-full":
        # Full verification including hostname
        ca_cert = os.getenv("POSTGRES_SSL_CA")
        if ca_cert:
            ctx.load_verify_locations(ca_cert)
        ctx.check_hostname = True
        ctx.verify_mode = ssl.CERT_REQUIRED

    return ctx


def get_database_url() -> str:
    """Build database URL from environment variables."""
    # Never include password in URL for logging safety
    host = os.getenv("POSTGRES_HOST", "localhost")
    port = os.getenv("POSTGRES_PORT", "5432")
    database = os.getenv("POSTGRES_DB", "ragpipeline")
    user = os.getenv("POSTGRES_USER", "raguser")

    return f"postgresql+asyncpg://{user}@{host}:{port}/{database}"


def create_engine_with_ssl():
    """Create SQLAlchemy engine with SSL support."""
    database_url = get_database_url()
    password = os.getenv("POSTGRES_PASSWORD")
    ssl_context = create_ssl_context()

    connect_args = {"password": password}

    if ssl_context:
        connect_args["ssl"] = ssl_context

    return create_async_engine(
        database_url,
        connect_args=connect_args,
        pool_size=20,
        max_overflow=10,
        pool_pre_ping=True,
        # Don't log connection args (contains password context)
        echo=False,
    )


# Session factory
engine = create_engine_with_ssl()
AsyncSessionLocal = sessionmaker(
    engine,
    class_=AsyncSession,
    expire_on_commit=False,
)


async def get_db_session() -> AsyncSession:
    """Dependency for getting database session."""
    async with AsyncSessionLocal() as session:
        try:
            yield session
        finally:
            await session.close()
```

```python
# services/shared/cache/redis_client.py

import ssl
import os
from redis.asyncio import Redis, ConnectionPool

def create_redis_ssl_context() -> ssl.SSLContext | None:
    """Create SSL context for Redis connection."""
    use_tls = os.getenv("REDIS_TLS_ENABLED", "false").lower() == "true"

    if not use_tls:
        return None

    ctx = ssl.create_default_context()

    ca_cert = os.getenv("REDIS_TLS_CA")
    if ca_cert:
        ctx.load_verify_locations(ca_cert)

    client_cert = os.getenv("REDIS_TLS_CERT")
    client_key = os.getenv("REDIS_TLS_KEY")
    if client_cert and client_key:
        ctx.load_cert_chain(client_cert, client_key)

    # Verify server certificate in production
    if os.getenv("ENVIRONMENT") == "production":
        ctx.check_hostname = True
        ctx.verify_mode = ssl.CERT_REQUIRED
    else:
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE

    return ctx


def create_redis_client() -> Redis:
    """Create Redis client with TLS and auth."""
    host = os.getenv("REDIS_HOST", "localhost")
    port = int(os.getenv("REDIS_PORT", "6379"))
    password = os.getenv("REDIS_PASSWORD")
    db = int(os.getenv("REDIS_DB", "0"))
    ssl_context = create_redis_ssl_context()

    return Redis(
        host=host,
        port=port,
        password=password,
        db=db,
        ssl=ssl_context,
        decode_responses=True,
        socket_timeout=5.0,
        socket_connect_timeout=5.0,
        retry_on_timeout=True,
    )


# Redis ACL configuration (server-side)
REDIS_ACL_RULES = """
# Application user - limited commands

user rag_cache on >{password} ~cache:* &* +get +set +setex +del +exists +expire
user rag_celery on >{password} ~celery:* &* +@list +@string +@set +@connection
```

```python
# services/shared/search/opensearch_client.py

import os
import ssl
from opensearchpy import AsyncOpenSearch
from typing import Optional

def create_opensearch_ssl_context() -> ssl.SSLContext | None:
    """Create SSL context for OpenSearch."""
    use_ssl = os.getenv("OPENSEARCH_SSL_ENABLED", "false").lower() == "true"

    if not use_ssl:
        return None

    ctx = ssl.create_default_context()

    ca_cert = os.getenv("OPENSEARCH_SSL_CA")
    if ca_cert:
        ctx.load_verify_locations(ca_cert)

    # Client certificate authentication
    client_cert = os.getenv("OPENSEARCH_SSL_CERT")
    client_key = os.getenv("OPENSEARCH_SSL_KEY")
    if client_cert and client_key:
        ctx.load_cert_chain(client_cert, client_key)

    if os.getenv("ENVIRONMENT") == "production":
        ctx.check_hostname = True
        ctx.verify_mode = ssl.CERT_REQUIRED
    else:
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE

    return ctx


def create_opensearch_client() -> AsyncOpenSearch:
    """Create OpenSearch client with security."""
    hosts = os.getenv("OPENSEARCH_HOSTS", "localhost:9200").split(",")

    # Parse hosts into proper format
    parsed_hosts = []
    for host in hosts:
        if ":" in host:
            hostname, port = host.split(":")
            parsed_hosts.append({"host": hostname, "port": int(port)})
        else:
            parsed_hosts.append({"host": host, "port": 9200})

    # Authentication
    username = os.getenv("OPENSEARCH_USERNAME")
    password = os.getenv("OPENSEARCH_PASSWORD")
    http_auth = (username, password) if username and password else None

    # SSL
    use_ssl = os.getenv("OPENSEARCH_SSL_ENABLED", "false").lower() == "true"
    ssl_context = create_opensearch_ssl_context()

    return AsyncOpenSearch(
        hosts=parsed_hosts,
        http_auth=http_auth,
        use_ssl=use_ssl,
        ssl_context=ssl_context,
        verify_certs=os.getenv("ENVIRONMENT") == "production",
        connection_class=None,  # Use default async connection
        timeout=30,
        max_retries=3,
        retry_on_timeout=True,
```

### Sanitized Connection Logging

```python
# services/shared/logging/sanitizer.py

import re
from typing import Any
import structlog

# Patterns to sanitize in logs
SENSITIVE_PATTERNS = [
    (r"password=[\w\-]+", "password=***"),
    (r"pwd=[\w\-]+", "pwd=***"),
    (r"secret=[\w\-]+", "secret=***"),
    (r"token=[\w\-\.]+", "token=***"),
    (r"api[_-]?key=[\w\-]+", "api_key=***"),
    (r"://\w+:\w+@", "://***:***@"),  # URLs with credentials
    (r"Bearer [\w\-\.]+", "Bearer ***"),
    (r"Basic [\w\+/=]+", "Basic ***"),
]

def sanitize_value(value: Any) -> Any:
    """Sanitize sensitive data from a value."""
    if not isinstance(value, str):
        return value

    result = value
    for pattern, replacement in SENSITIVE_PATTERNS:
        result = re.sub(pattern, replacement, result, flags=re.IGNORECASE)

    return result


def sanitize_dict(data: dict) -> dict:
    """Recursively sanitize sensitive data from a dictionary."""
    sensitive_keys = {"password", "secret", "token", "api_key", "apikey", "auth", "credential"}

    result = {}
    for key, value in data.items():
        lower_key = key.lower()

        # Mask entire value for sensitive keys
        if any(s in lower_key for s in sensitive_keys):
            result[key] = "***"
        elif isinstance(value, dict):
            result[key] = sanitize_dict(value)
        elif isinstance(value, list):
            result[key] = [sanitize_dict(v) if isinstance(v, dict) else sanitize_value(v) for v in value]
        else:
            result[key] = sanitize_value(value)

    return result


class SanitizingProcessor:
    """Structlog processor that sanitizes sensitive data."""

    def __call__(self, logger, method_name, event_dict):
        return sanitize_dict(event_dict)


# Configure structlog with sanitizer
structlog.configure(
    processors=[
        structlog.stdlib.filter_by_level,
        structlog.stdlib.add_logger_name,
        structlog.stdlib.add_log_level,
        structlog.stdlib.PositionalArgumentsFormatter(),
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.StackInfoRenderer(),
        SanitizingProcessor(),  # Add sanitizer
        structlog.processors.format_exc_info,
        structlog.processors.UnicodeDecoder(),
        structlog.processors.JSONRenderer(),
    ],
    wrapper_class=structlog.stdlib.BoundLogger,
    context_class=dict,
    logger_factory=structlog.stdlib.LoggerFactory(),
    cache_logger_on_first_use=True,
)
```

### Health Check with TLS Verification

```python
# services/shared/health/database_health.py

import asyncio
from dataclasses import dataclass
from typing import Optional
import structlog

logger = structlog.get_logger()

@dataclass
class DatabaseHealthStatus:
    """Health status for a database."""
    name: str
    healthy: bool
    latency_ms: float
    ssl_enabled: bool
    error: Optional[str] = None

async def check_postgres_health(engine) -> DatabaseHealthStatus:
    """Check PostgreSQL health including SSL status."""
    import time

    start = time.monotonic()
    try:
        async with engine.connect() as conn:
            result = await conn.execute("SELECT 1, ssl_is_used()")
            row = result.fetchone()
            ssl_enabled = row[1] if row else False

        latency = (time.monotonic() - start) * 1000

        return DatabaseHealthStatus(
            name="postgresql",
            healthy=True,
            latency_ms=latency,
            ssl_enabled=ssl_enabled,
        )
    except Exception as e:
        latency = (time.monotonic() - start) * 1000
        logger.error("postgres_health_check_failed", error=str(e))
        return DatabaseHealthStatus(
            name="postgresql",
            healthy=False,
            latency_ms=latency,
            ssl_enabled=False,
            error=str(e),
        )

async def check_redis_health(redis_client) -> DatabaseHealthStatus:
    """Check Redis health including TLS status."""
    import time

    start = time.monotonic()
    try:
        await redis_client.ping()
        # Check if connection is using TLS
        ssl_enabled = redis_client.connection_pool.connection_kwargs.get("ssl") is not None

        latency = (time.monotonic() - start) * 1000

        return DatabaseHealthStatus(
            name="redis",
            healthy=True,
            latency_ms=latency,
            ssl_enabled=ssl_enabled,
        )
    except Exception as e:
        latency = (time.monotonic() - start) * 1000
        logger.error("redis_health_check_failed", error=str(e))
        return DatabaseHealthStatus(
            name="redis",
            healthy=False,
            latency_ms=latency,
            ssl_enabled=False,
            error=str(e),
        )

async def check_opensearch_health(os_client) -> DatabaseHealthStatus:
    """Check OpenSearch health including TLS status."""
    import time

    start = time.monotonic()
    try:
        health = await os_client.cluster.health()
        ssl_enabled = os_client.transport.use_ssl

        latency = (time.monotonic() - start) * 1000

        return DatabaseHealthStatus(
            name="opensearch",
            healthy=health["status"] in ("green", "yellow"),
            latency_ms=latency,
            ssl_enabled=ssl_enabled,
        )
    except Exception as e:
        latency = (time.monotonic() - start) * 1000
        logger.error("opensearch_health_check_failed", error=str(e))
        return DatabaseHealthStatus(
            name="opensearch",
            healthy=False,
            latency_ms=latency,
            ssl_enabled=False,
            error=str(e),
        )
```

## Implementation Steps

1. **Generate TLS certificates**
   - Create CA for internal PKI
   - Generate server certs for each database
   - Generate client certs for services

2. **Configure PostgreSQL**
   - Enable SSL in postgresql.conf
   - Configure pg_hba.conf for SSL requirement
   - Test connections with SSL

3. **Configure Redis**
   - Enable TLS in redis.conf
   - Configure ACL for service users
   - Test TLS connections

4. **Configure OpenSearch**
   - Enable security plugin
   - Configure TLS and authentication
   - Create service users and roles

5. **Update application code**
   - Add SSL context creation
   - Update connection factories
   - Add sanitizing log processor

6. **Deploy and verify**
   - Deploy updated secrets
   - Roll out service updates
   - Verify SSL in health checks
