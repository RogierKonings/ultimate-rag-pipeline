# US-10.1.2: Background Index Reconciler

> **Initiative:** 1 - Multi-Store Indexing & ACL Bulletproofing
> **Priority:** P0
> **Effort:** Large (4-5 days)
> **Status:** Draft

## Summary

Implement an automated background process that detects and repairs inconsistencies between PostgreSQL (authoritative source), Qdrant (vector store), and OpenSearch (keyword store) to ensure retrieval quality without manual intervention.

## Problem Statement

Index inconsistencies can occur due to:
- Partial failures during indexing (one store succeeds, another fails)
- Network issues causing timeouts
- Service restarts during indexing operations
- Manual data corrections in PostgreSQL

**Current state**: The ingestion pipeline in [ingest.py](services/ingestion/tasks/ingest.py) has retry logic but no mechanism to detect or repair drift between stores after initial indexing.

**Impact**:
- Documents may be searchable in one store but not another
- Deleted documents may persist in vector/keyword stores
- No automated recovery from partial failures
- Manual intervention required to identify and fix issues

## User Story

**As a** system operator
**I want** automatic detection and repair of index inconsistencies
**So that** retrieval quality is maintained without manual intervention

## Acceptance Criteria

### AC-1: Reconciliation Task Implementation
- [ ] New Celery task `reconcile_index(tenant_id, document_id=None, dry_run=False)`
- [ ] Task runs on dedicated `maintenance` queue with lower priority
- [ ] Supports full tenant reconciliation or single document
- [ ] Dry-run mode reports issues without making changes
- [ ] Returns detailed `ReconciliationResult` with actions taken

### AC-2: Inconsistency Detection
- [ ] Compares PostgreSQL document/chunk state with Qdrant vectors
- [ ] Compares PostgreSQL document/chunk state with OpenSearch documents
- [ ] Detects: missing chunks, orphaned entries, status mismatches
- [ ] Handles large datasets efficiently (batched queries)

### AC-3: Automatic Repair Actions
- [ ] Re-indexes chunks missing from Qdrant (re-embeds if needed)
- [ ] Re-indexes chunks missing from OpenSearch
- [ ] Deletes orphaned vectors (document deleted in PostgreSQL)
- [ ] Deletes orphaned OpenSearch documents
- [ ] Updates status fields in PostgreSQL (US-10.1.1 dependency)

### AC-4: Scheduling & Administration
- [ ] Configurable per-tenant scheduling via cron expression
- [ ] Admin API endpoint to trigger manual reconciliation
- [ ] Default: nightly reconciliation during low-traffic hours
- [ ] Rate limiting to prevent overloading stores

### AC-5: Observability
- [ ] Prometheus metrics: `index_reconciliation_runs_total{tenant_id, status}`
- [ ] Prometheus metrics: `index_orphans_cleaned_total{store}`
- [ ] Prometheus metrics: `index_missing_reindexed_total{store}`
- [ ] Structured logging for all reconciliation actions
- [ ] Alert on reconciliation failures

### Data Structures

```python
# services/ingestion/tasks/reconcile.py

from dataclasses import dataclass, field
from enum import Enum
from typing import Literal

class ReconciliationAction(str, Enum):
    """Actions taken during reconciliation."""
    REINDEX_QDRANT = "reindex_qdrant"
    REINDEX_OPENSEARCH = "reindex_opensearch"
    DELETE_ORPHAN_QDRANT = "delete_orphan_qdrant"
    DELETE_ORPHAN_OPENSEARCH = "delete_orphan_opensearch"
    UPDATE_STATUS = "update_status"
    SKIP_NO_ACTION = "skip_no_action"

@dataclass
class ReconciliationIssue:
    """A single inconsistency found during reconciliation."""
    document_id: str
    chunk_id: str | None
    issue_type: Literal["missing_qdrant", "missing_opensearch", "orphan_qdrant", "orphan_opensearch", "status_mismatch"]
    action_taken: ReconciliationAction
    success: bool
    error_message: str | None = None

@dataclass
class ReconciliationResult:
    """Result of a reconciliation run."""
    tenant_id: str
    document_id: str | None  # None for full tenant reconciliation
    dry_run: bool
    started_at: datetime
    completed_at: datetime
    documents_scanned: int = 0
    chunks_scanned: int = 0
    issues_found: int = 0
    issues_fixed: int = 0
    issues_failed: int = 0
    issues: list[ReconciliationIssue] = field(default_factory=list)

    @property
    def duration_seconds(self) -> float:
        return (self.completed_at - self.started_at).total_seconds()

    @property
    def success_rate(self) -> float:
        if self.issues_found == 0:
            return 1.0
        return self.issues_fixed / self.issues_found
```

### Celery Task

```python
# services/ingestion/tasks/reconcile.py

from celery import shared_task
from shared.database.session import async_session_factory
from shared.database.models.document import Document, IndexStatus
from shared.database.models.chunk import Chunk
from shared.vectorstore.qdrant_client import QdrantClient
from shared.search.opensearch_client import OpenSearchClient

import structlog

logger = structlog.get_logger(__name__)

@shared_task(
    queue="maintenance",
    bind=True,
    max_retries=1,
    soft_time_limit=3600,  # 1 hour soft limit
    time_limit=3900,       # 1 hour 5 min hard limit
)
async def reconcile_index(
    self,
    tenant_id: str,
    document_id: str | None = None,
    dry_run: bool = False,
    batch_size: int = 100,
) -> dict:
    """
    Reconcile PostgreSQL authoritative state with Qdrant and OpenSearch.

    Args:
        tenant_id: Tenant to reconcile
        document_id: Optional specific document (None = all tenant documents)
        dry_run: If True, report issues without fixing
        batch_size: Number of documents to process per batch

    Returns:
        ReconciliationResult as dict
    """
    started_at = datetime.utcnow()
    result = ReconciliationResult(
        tenant_id=tenant_id,
        document_id=document_id,
        dry_run=dry_run,
        started_at=started_at,
        completed_at=started_at,  # Updated at end
    )

    logger.info(
        "reconciliation_started",
        tenant_id=tenant_id,
        document_id=document_id,
        dry_run=dry_run,
    )

    async with async_session_factory() as session:
        qdrant = QdrantClient()
        opensearch = OpenSearchClient()

        try:
            # Phase 1: Find missing chunks in external stores
            await _reconcile_missing_chunks(
                session, qdrant, opensearch, tenant_id, document_id,
                batch_size, dry_run, result
            )

            # Phase 2: Find orphaned entries in external stores
            await _reconcile_orphaned_entries(
                session, qdrant, opensearch, tenant_id, document_id,
                batch_size, dry_run, result
            )

            # Phase 3: Update PostgreSQL status fields
            await _update_document_statuses(
                session, tenant_id, document_id, dry_run, result
            )

        except Exception as e:
            logger.error(
                "reconciliation_failed",
                tenant_id=tenant_id,
                error=str(e),
            )
            raise

    result.completed_at = datetime.utcnow()

    # Update metrics
    _update_reconciliation_metrics(result)

    logger.info(
        "reconciliation_completed",
        tenant_id=tenant_id,
        duration_seconds=result.duration_seconds,
        documents_scanned=result.documents_scanned,
        issues_found=result.issues_found,
        issues_fixed=result.issues_fixed,
    )

    return asdict(result)


async def _reconcile_missing_chunks(
    session: AsyncSession,
    qdrant: QdrantClient,
    opensearch: OpenSearchClient,
    tenant_id: str,
    document_id: str | None,
    batch_size: int,
    dry_run: bool,
    result: ReconciliationResult,
) -> None:
    """Find chunks in PostgreSQL that are missing from external stores."""

    # Query active documents with their chunks
    stmt = (
        select(Document)
        .options(selectinload(Document.chunks))
        .where(
            Document.tenant_id == tenant_id,
            Document.status == "active",
        )
    )
    if document_id:
        stmt = stmt.where(Document.id == document_id)

    # Process in batches
    offset = 0
    while True:
        batch_stmt = stmt.limit(batch_size).offset(offset)
        docs = (await session.execute(batch_stmt)).scalars().all()

        if not docs:
            break

        for doc in docs:
            result.documents_scanned += 1
            result.chunks_scanned += len(doc.chunks)

            chunk_ids = [str(c.id) for c in doc.chunks]

            # Check Qdrant
            qdrant_ids = await qdrant.get_existing_chunk_ids(
                tenant_id=tenant_id,
                chunk_ids=chunk_ids,
            )
            missing_qdrant = set(chunk_ids) - set(qdrant_ids)

            for chunk_id in missing_qdrant:
                chunk = next(c for c in doc.chunks if str(c.id) == chunk_id)
                issue = await _handle_missing_qdrant(
                    session, qdrant, chunk, dry_run
                )
                result.issues.append(issue)
                result.issues_found += 1
                if issue.success:
                    result.issues_fixed += 1
                else:
                    result.issues_failed += 1

            # Check OpenSearch
            opensearch_ids = await opensearch.get_existing_chunk_ids(
                tenant_id=tenant_id,
                chunk_ids=chunk_ids,
            )
            missing_opensearch = set(chunk_ids) - set(opensearch_ids)

            for chunk_id in missing_opensearch:
                chunk = next(c for c in doc.chunks if str(c.id) == chunk_id)
                issue = await _handle_missing_opensearch(
                    session, opensearch, chunk, dry_run
                )
                result.issues.append(issue)
                result.issues_found += 1
                if issue.success:
                    result.issues_fixed += 1
                else:
                    result.issues_failed += 1

        offset += batch_size


async def _reconcile_orphaned_entries(
    session: AsyncSession,
    qdrant: QdrantClient,
    opensearch: OpenSearchClient,
    tenant_id: str,
    document_id: str | None,
    batch_size: int,
    dry_run: bool,
    result: ReconciliationResult,
) -> None:
    """Find entries in external stores that don't exist in PostgreSQL."""

    # Get all chunk IDs from PostgreSQL for this tenant
    stmt = (
        select(Chunk.id)
        .join(Document)
        .where(
            Document.tenant_id == tenant_id,
            Document.status == "active",
        )
    )
    if document_id:
        stmt = stmt.where(Document.id == document_id)

    pg_chunk_ids = set(
        str(id) for id in (await session.execute(stmt)).scalars().all()
    )

    # Get all chunk IDs from Qdrant
    qdrant_chunk_ids = await qdrant.get_all_chunk_ids(tenant_id=tenant_id)
    orphaned_qdrant = set(qdrant_chunk_ids) - pg_chunk_ids

    for chunk_id in orphaned_qdrant:
        issue = await _handle_orphan_qdrant(qdrant, chunk_id, tenant_id, dry_run)
        result.issues.append(issue)
        result.issues_found += 1
        if issue.success:
            result.issues_fixed += 1
        else:
            result.issues_failed += 1

    # Get all chunk IDs from OpenSearch
    opensearch_chunk_ids = await opensearch.get_all_chunk_ids(tenant_id=tenant_id)
    orphaned_opensearch = set(opensearch_chunk_ids) - pg_chunk_ids

    for chunk_id in orphaned_opensearch:
        issue = await _handle_orphan_opensearch(
            opensearch, chunk_id, tenant_id, dry_run
        )
        result.issues.append(issue)
        result.issues_found += 1
        if issue.success:
            result.issues_fixed += 1
        else:
            result.issues_failed += 1


async def _handle_missing_qdrant(
    session: AsyncSession,
    qdrant: QdrantClient,
    chunk: Chunk,
    dry_run: bool,
) -> ReconciliationIssue:
    """Re-index a chunk missing from Qdrant."""
    issue = ReconciliationIssue(
        document_id=str(chunk.document_id),
        chunk_id=str(chunk.id),
        issue_type="missing_qdrant",
        action_taken=ReconciliationAction.SKIP_NO_ACTION if dry_run else ReconciliationAction.REINDEX_QDRANT,
        success=True,
    )

    if dry_run:
        return issue

    try:
        # Re-embed if no cached embedding
        embedding = await get_or_create_embedding(chunk)
        await qdrant.upsert_chunk(chunk, embedding)
        logger.info("reindexed_missing_qdrant", chunk_id=str(chunk.id))
    except Exception as e:
        issue.success = False
        issue.error_message = str(e)
        logger.error("reindex_qdrant_failed", chunk_id=str(chunk.id), error=str(e))

    return issue


async def _handle_orphan_qdrant(
    qdrant: QdrantClient,
    chunk_id: str,
    tenant_id: str,
    dry_run: bool,
) -> ReconciliationIssue:
    """Delete an orphaned entry from Qdrant."""
    issue = ReconciliationIssue(
        document_id="unknown",
        chunk_id=chunk_id,
        issue_type="orphan_qdrant",
        action_taken=ReconciliationAction.SKIP_NO_ACTION if dry_run else ReconciliationAction.DELETE_ORPHAN_QDRANT,
        success=True,
    )

    if dry_run:
        return issue

    try:
        await qdrant.delete_by_chunk_id(chunk_id, tenant_id)
        logger.info("deleted_orphan_qdrant", chunk_id=chunk_id)
    except Exception as e:
        issue.success = False
        issue.error_message = str(e)
        logger.error("delete_orphan_qdrant_failed", chunk_id=chunk_id, error=str(e))

    return issue
```

# services/ingestion/api/routes.py

from pydantic import BaseModel

class ReconcileRequest(BaseModel):
    tenant_id: str
    document_id: str | None = None
    dry_run: bool = True  # Default to dry-run for safety

class ReconcileResponse(BaseModel):
    job_id: str
    status: str
    message: str

@router.post("/admin/reconcile", response_model=ReconcileResponse)
async def trigger_reconciliation(
    request: ReconcileRequest,
    current_user: User = Depends(require_admin),
) -> ReconcileResponse:
    """
    Trigger index reconciliation for a tenant.

    Requires admin privileges.
    """
    from ingestion.tasks.reconcile import reconcile_index

    task = reconcile_index.delay(
        tenant_id=request.tenant_id,
        document_id=request.document_id,
        dry_run=request.dry_run,
    )

    return ReconcileResponse(
        job_id=task.id,
        status="queued",
        message=f"Reconciliation {'dry-run ' if request.dry_run else ''}queued for tenant {request.tenant_id}",
    )


@router.get("/admin/reconcile/{job_id}", response_model=dict)
async def get_reconciliation_status(
    job_id: str,
    current_user: User = Depends(require_admin),
) -> dict:
    """Get status of a reconciliation job."""
    from celery.result import AsyncResult

    result = AsyncResult(job_id)

    if result.state == "PENDING":
        return {"status": "pending", "job_id": job_id}
    elif result.state == "SUCCESS":
        return {"status": "completed", "job_id": job_id, "result": result.result}
    elif result.state == "FAILURE":
        return {"status": "failed", "job_id": job_id, "error": str(result.result)}
    else:
        return {"status": result.state.lower(), "job_id": job_id}
```

@shared_task(queue="maintenance")
async def reconcile_all_tenants(dry_run: bool = False) -> dict:
    """Run reconciliation for all active tenants."""
    async with async_session_factory() as session:
        stmt = select(distinct(Document.tenant_id)).where(Document.status == "active")
        tenant_ids = (await session.execute(stmt)).scalars().all()

    results = {}
    for tenant_id in tenant_ids:
        try:
            result = await reconcile_index(tenant_id, dry_run=dry_run)
            results[tenant_id] = result
        except Exception as e:
            results[tenant_id] = {"error": str(e)}
            logger.error("tenant_reconciliation_failed", tenant_id=tenant_id, error=str(e))

    return results

# services/ingestion/observability/metrics.py

from prometheus_client import Counter, Histogram

reconciliation_runs = Counter(
    "index_reconciliation_runs_total",
    "Total reconciliation runs",
    ["tenant_id", "status"],  # status: success, failure, partial
)

reconciliation_duration = Histogram(
    "index_reconciliation_duration_seconds",
    "Duration of reconciliation runs",
    ["tenant_id"],
    buckets=[60, 300, 600, 1800, 3600],  # 1min, 5min, 10min, 30min, 1hr
)

orphans_cleaned = Counter(
    "index_orphans_cleaned_total",
    "Total orphaned entries cleaned",
    ["store"],  # qdrant, opensearch
)

missing_reindexed = Counter(
    "index_missing_reindexed_total",
    "Total missing entries re-indexed",
    ["store"],
)

def _update_reconciliation_metrics(result: ReconciliationResult) -> None:
    """Update Prometheus metrics from reconciliation result."""
    status = "success" if result.issues_failed == 0 else "partial" if result.issues_fixed > 0 else "failure"

    reconciliation_runs.labels(
        tenant_id=result.tenant_id,
        status=status,
    ).inc()

    reconciliation_duration.labels(
        tenant_id=result.tenant_id,
    ).observe(result.duration_seconds)

    for issue in result.issues:
        if issue.success:
            if issue.action_taken == ReconciliationAction.DELETE_ORPHAN_QDRANT:
                orphans_cleaned.labels(store="qdrant").inc()
            elif issue.action_taken == ReconciliationAction.DELETE_ORPHAN_OPENSEARCH:
                orphans_cleaned.labels(store="opensearch").inc()
            elif issue.action_taken == ReconciliationAction.REINDEX_QDRANT:
                missing_reindexed.labels(store="qdrant").inc()
            elif issue.action_taken == ReconciliationAction.REINDEX_OPENSEARCH:
                missing_reindexed.labels(store="opensearch").inc()
```

## Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Reconciliation overloads stores | Medium | High | Rate limiting, batch processing, off-peak scheduling |
| Race condition with active ingestion | Medium | Medium | Use optimistic locking, skip recently modified docs |
| Large tenants timeout | Medium | Medium | Batched processing, resumable reconciliation |
| Embedding costs for re-indexing | Low | Medium | Use cached embeddings when available |
