# US-10.2.1: Retrieval Service Resilience Layer

> **Initiative:** 2 - End-to-End Resilience & Adaptive Degradation
> **Priority:** P0
> **Effort:** Large (4-5 days)
> **Status:** Draft

## Summary

Add circuit breakers and degradation modes to the retrieval service, enabling graceful degradation when Qdrant, OpenSearch, or the reranker become unhealthy.

## Problem Statement

**Current state**: The orchestrator service has circuit breakers in [resilience/](services/orchestrator/resilience/) but the retrieval service lacks explicit degradation handling:
- Health checks exist but don't drive behavior
- Service fails entirely if one backend is down
- No adaptive response to partial failures
- Users get errors instead of degraded results

**Impact**:
- Single backend failure causes complete retrieval failure
- Poor user experience during partial outages
- No visibility into degradation state
- Cascading failures to orchestrator

## User Story

**As a** system operator
**I want** the retrieval service to gracefully degrade when components fail
**So that** users get results even during partial outages

## Acceptance Criteria

### AC-1: Circuit Breakers for Backend Services
- [ ] Circuit breaker for Qdrant with configurable thresholds
- [ ] Circuit breaker for OpenSearch with configurable thresholds
- [ ] Circuit breaker for LLM Gateway (reranking)
- [ ] States: CLOSED (healthy), OPEN (unhealthy), HALF_OPEN (testing)

### AC-2: Degradation Modes
- [ ] `HYBRID_FULL` - All components healthy (default)
- [ ] `SEMANTIC_ONLY` - OpenSearch unhealthy, use Qdrant only
- [ ] `KEYWORD_ONLY` - Qdrant unhealthy, use OpenSearch only
- [ ] `HYBRID_NO_RERANK` - Reranker unhealthy, skip reranking
- [ ] `MINIMAL` - Multiple failures, best effort

### AC-3: Automatic Mode Selection
- [ ] `DegradationManager` determines mode from circuit states
- [ ] Mode checked before each search operation
- [ ] Seamless fallback without user intervention

### AC-4: Health Endpoint Enhancement
- [ ] `/health` includes `degradation_level` field
- [ ] `/health` includes status of each circuit breaker
- [ ] Prometheus metric: `retrieval_degradation_mode{mode}`

### AC-5: Response Metadata
- [ ] Search response includes `degradation_mode` used
- [ ] Response includes which components were skipped
- [ ] Logging of all degradation events

# services/retrieval/resilience/circuit_breaker.py

from enum import Enum
from dataclasses import dataclass, field
from datetime import datetime, timedelta
import asyncio
import structlog

logger = structlog.get_logger(__name__)

class CircuitState(str, Enum):
    CLOSED = "closed"      # Healthy, allowing requests
    OPEN = "open"          # Unhealthy, blocking requests
    HALF_OPEN = "half_open"  # Testing if recovered

@dataclass
class CircuitBreakerConfig:
    """Configuration for circuit breaker behavior."""
    failure_threshold: int = 5          # Failures before opening
    success_threshold: int = 3          # Successes in half-open to close
    timeout_seconds: float = 30.0       # Time before half-open
    half_open_max_calls: int = 3        # Max calls in half-open state

@dataclass
class CircuitBreaker:
    """
    Circuit breaker for protecting backend services.

    Tracks failures and automatically opens circuit when threshold reached.
    After timeout, allows limited traffic to test recovery.
    """
    name: str
    config: CircuitBreakerConfig = field(default_factory=CircuitBreakerConfig)
    state: CircuitState = CircuitState.CLOSED
    failure_count: int = 0
    success_count: int = 0
    last_failure_time: datetime | None = None
    half_open_calls: int = 0
    _lock: asyncio.Lock = field(default_factory=asyncio.Lock)

    async def call(
        self,
        func,
        *args,
        fallback=None,
        **kwargs,
    ):
        """
        Execute function with circuit breaker protection.

        Args:
            func: Async function to call
            fallback: Optional fallback function if circuit is open
            *args, **kwargs: Arguments to pass to func

        Returns:
            Result from func, fallback, or raises CircuitOpenError
        """
        async with self._lock:
            # Check if we should allow the call
            if not await self._should_allow_call():
                logger.warning(
                    "circuit_breaker_rejected",
                    breaker=self.name,
                    state=self.state.value,
                )
                if fallback:
                    return await fallback(*args, **kwargs)
                raise CircuitOpenError(f"Circuit {self.name} is open")

        # Execute the call
        try:
            result = await func(*args, **kwargs)
            await self._record_success()
            return result
        except Exception as e:
            await self._record_failure(e)
            if fallback:
                return await fallback(*args, **kwargs)
            raise

    async def _should_allow_call(self) -> bool:
        """Determine if a call should be allowed."""
        if self.state == CircuitState.CLOSED:
            return True

        if self.state == CircuitState.OPEN:
            # Check if timeout has passed
            if self._timeout_expired():
                self.state = CircuitState.HALF_OPEN
                self.half_open_calls = 0
                self.success_count = 0
                logger.info(
                    "circuit_breaker_half_open",
                    breaker=self.name,
                )
                return True
            return False

        if self.state == CircuitState.HALF_OPEN:
            # Allow limited calls in half-open
            if self.half_open_calls < self.config.half_open_max_calls:
                self.half_open_calls += 1
                return True
            return False

        return False

    def _timeout_expired(self) -> bool:
        """Check if circuit open timeout has expired."""
        if self.last_failure_time is None:
            return True
        elapsed = datetime.utcnow() - self.last_failure_time
        return elapsed.total_seconds() >= self.config.timeout_seconds

    async def _record_success(self) -> None:
        """Record a successful call."""
        async with self._lock:
            if self.state == CircuitState.HALF_OPEN:
                self.success_count += 1
                if self.success_count >= self.config.success_threshold:
                    self.state = CircuitState.CLOSED
                    self.failure_count = 0
                    logger.info(
                        "circuit_breaker_closed",
                        breaker=self.name,
                    )
            elif self.state == CircuitState.CLOSED:
                # Reset failure count on success
                self.failure_count = max(0, self.failure_count - 1)

    async def _record_failure(self, error: Exception) -> None:
        """Record a failed call."""
        async with self._lock:
            self.failure_count += 1
            self.last_failure_time = datetime.utcnow()

            logger.warning(
                "circuit_breaker_failure",
                breaker=self.name,
                failure_count=self.failure_count,
                error=str(error),
            )

            if self.state == CircuitState.HALF_OPEN:
                # Any failure in half-open reopens circuit
                self.state = CircuitState.OPEN
                logger.warning(
                    "circuit_breaker_reopened",
                    breaker=self.name,
                )
            elif self.state == CircuitState.CLOSED:
                if self.failure_count >= self.config.failure_threshold:
                    self.state = CircuitState.OPEN
                    logger.warning(
                        "circuit_breaker_opened",
                        breaker=self.name,
                        failure_count=self.failure_count,
                    )

    def get_status(self) -> dict:
        """Get current circuit breaker status."""
        return {
            "name": self.name,
            "state": self.state.value,
            "failure_count": self.failure_count,
            "success_count": self.success_count,
            "last_failure": self.last_failure_time.isoformat() if self.last_failure_time else None,
        }


class CircuitOpenError(Exception):
    """Raised when circuit breaker is open."""
    pass
```

# services/retrieval/resilience/degradation.py

from enum import Enum
from dataclasses import dataclass
import structlog

logger = structlog.get_logger(__name__)

class DegradationMode(str, Enum):
    """Retrieval service degradation modes."""
    HYBRID_FULL = "hybrid_full"          # All healthy
    SEMANTIC_ONLY = "semantic_only"      # OpenSearch down
    KEYWORD_ONLY = "keyword_only"        # Qdrant down
    HYBRID_NO_RERANK = "hybrid_no_rerank"  # Reranker down
    MINIMAL = "minimal"                   # Multiple failures

@dataclass
class DegradationStatus:
    """Current degradation status with details."""
    mode: DegradationMode
    qdrant_healthy: bool
    opensearch_healthy: bool
    reranker_healthy: bool
    components_available: list[str]
    components_unavailable: list[str]

class RetrievalDegradationManager:
    """
    Manages degradation modes based on circuit breaker states.

    Determines which retrieval mode to use based on health of
    backend components.
    """

    def __init__(
        self,
        qdrant_breaker: CircuitBreaker,
        opensearch_breaker: CircuitBreaker,
        reranker_breaker: CircuitBreaker,
    ):
        self.qdrant_breaker = qdrant_breaker
        self.opensearch_breaker = opensearch_breaker
        self.reranker_breaker = reranker_breaker

    def get_current_mode(self) -> DegradationMode:
        """Determine current degradation mode from circuit states."""
        qdrant_ok = self.qdrant_breaker.state != CircuitState.OPEN
        opensearch_ok = self.opensearch_breaker.state != CircuitState.OPEN
        reranker_ok = self.reranker_breaker.state != CircuitState.OPEN

        if qdrant_ok and opensearch_ok and reranker_ok:
            return DegradationMode.HYBRID_FULL

        if not qdrant_ok and not opensearch_ok:
            return DegradationMode.MINIMAL

        if not qdrant_ok:
            return DegradationMode.KEYWORD_ONLY

        if not opensearch_ok:
            return DegradationMode.SEMANTIC_ONLY

        if not reranker_ok:
            return DegradationMode.HYBRID_NO_RERANK

        return DegradationMode.HYBRID_FULL

    def get_status(self) -> DegradationStatus:
        """Get detailed degradation status."""
        mode = self.get_current_mode()

        qdrant_healthy = self.qdrant_breaker.state != CircuitState.OPEN
        opensearch_healthy = self.opensearch_breaker.state != CircuitState.OPEN
        reranker_healthy = self.reranker_breaker.state != CircuitState.OPEN

        available = []
        unavailable = []

        if qdrant_healthy:
            available.append("qdrant")
        else:
            unavailable.append("qdrant")

        if opensearch_healthy:
            available.append("opensearch")
        else:
            unavailable.append("opensearch")

        if reranker_healthy:
            available.append("reranker")
        else:
            unavailable.append("reranker")

        return DegradationStatus(
            mode=mode,
            qdrant_healthy=qdrant_healthy,
            opensearch_healthy=opensearch_healthy,
            reranker_healthy=reranker_healthy,
            components_available=available,
            components_unavailable=unavailable,
        )

    def should_use_semantic(self) -> bool:
        """Check if semantic search should be used."""
        mode = self.get_current_mode()
        return mode in (
            DegradationMode.HYBRID_FULL,
            DegradationMode.SEMANTIC_ONLY,
            DegradationMode.HYBRID_NO_RERANK,
        )

    def should_use_keyword(self) -> bool:
        """Check if keyword search should be used."""
        mode = self.get_current_mode()
        return mode in (
            DegradationMode.HYBRID_FULL,
            DegradationMode.KEYWORD_ONLY,
            DegradationMode.HYBRID_NO_RERANK,
        )

    def should_use_reranker(self) -> bool:
        """Check if reranker should be used."""
        mode = self.get_current_mode()
        return mode in (
            DegradationMode.HYBRID_FULL,
            DegradationMode.SEMANTIC_ONLY,
            DegradationMode.KEYWORD_ONLY,
        )

# services/retrieval/search/hybrid.py

class ResilientHybridSearcher:
    """
    Hybrid searcher with resilience and degradation support.

    Uses circuit breakers to protect against backend failures
    and automatically degrades to available components.
    """

    def __init__(
        self,
        semantic_searcher: SemanticSearcher,
        keyword_searcher: KeywordSearcher,
        reranker: Reranker,
        fusion: FusionStrategy,
        degradation_manager: RetrievalDegradationManager,
    ):
        self.semantic = semantic_searcher
        self.keyword = keyword_searcher
        self.reranker = reranker
        self.fusion = fusion
        self.degradation = degradation_manager

    async def search(
        self,
        query: str,
        query_embedding: list[float],
        user_context: UserContext,
        options: SearchOptions,
    ) -> HybridSearchResult:
        """
        Execute hybrid search with degradation handling.

        Automatically uses available components based on circuit states.
        """
        mode = self.degradation.get_current_mode()
        status = self.degradation.get_status()

        logger.info(
            "search_starting",
            degradation_mode=mode.value,
            components_available=status.components_available,
        )

        semantic_results = []
        keyword_results = []
        tasks = []

        # Launch searches based on degradation mode
        if self.degradation.should_use_semantic():
            tasks.append(self._search_semantic(query_embedding, user_context, options))
        else:
            tasks.append(asyncio.coroutine(lambda: [])())  # Empty placeholder

        if self.degradation.should_use_keyword():
            tasks.append(self._search_keyword(query, user_context, options))
        else:
            tasks.append(asyncio.coroutine(lambda: [])())

        # Execute in parallel
        results = await asyncio.gather(*tasks, return_exceptions=True)

        # Process results
        if not isinstance(results[0], Exception):
            semantic_results = results[0]
        else:
            logger.error("semantic_search_failed", error=str(results[0]))

        if not isinstance(results[1], Exception):
            keyword_results = results[1]
        else:
            logger.error("keyword_search_failed", error=str(results[1]))

        # Handle minimal mode (both failed)
        if not semantic_results and not keyword_results:
            logger.warning("both_searches_failed", mode=mode.value)
            return HybridSearchResult(
                results=[],
                mode=DegradationMode.MINIMAL,
                debug={"error": "All search backends unavailable"},
            )

        # Fusion
        if semantic_results and keyword_results:
            fused = self.fusion.fuse(semantic_results, keyword_results, options)
        else:
            fused = semantic_results or keyword_results

        # Reranking (if available)
        if self.degradation.should_use_reranker() and options.use_reranker:
            final = await self._rerank(query, fused, options)
        else:
            final = fused[:options.final_top_k]

        return HybridSearchResult(
            results=final,
            mode=mode,
            debug={
                "semantic_count": len(semantic_results),
                "keyword_count": len(keyword_results),
                "fused_count": len(fused),
                "final_count": len(final),
                "components_used": status.components_available,
                "components_skipped": status.components_unavailable,
            },
        )

    async def _search_semantic(
        self,
        embedding: list[float],
        user_context: UserContext,
        options: SearchOptions,
    ) -> list[SearchResult]:
        """Semantic search with circuit breaker."""
        return await self.degradation.qdrant_breaker.call(
            self.semantic.search,
            query_embedding=embedding,
            user_context=user_context,
            top_k=options.semantic_top_k,
            fallback=lambda *args, **kwargs: [],
        )

    async def _search_keyword(
        self,
        query: str,
        user_context: UserContext,
        options: SearchOptions,
    ) -> list[SearchResult]:
        """Keyword search with circuit breaker."""
        return await self.degradation.opensearch_breaker.call(
            self.keyword.search,
            query=query,
            user_context=user_context,
            top_k=options.keyword_top_k,
            fallback=lambda *args, **kwargs: [],
        )

    async def _rerank(
        self,
        query: str,
        results: list[SearchResult],
        options: SearchOptions,
    ) -> list[SearchResult]:
        """Rerank with circuit breaker."""
        return await self.degradation.reranker_breaker.call(
            self.reranker.rerank,
            query=query,
            results=results,
            top_k=options.rerank_top_k,
            fallback=lambda q, r, top_k: r[:top_k],  # Return unranked as fallback
        )
```

async def health_check(
    degradation_manager: RetrievalDegradationManager = Depends(get_degradation_manager),

            "keyword_search": status.opensearch_healthy,

from prometheus_client import Gauge, Counter

degradation_mode_gauge = Gauge(
    "retrieval_degradation_mode",
    "Current degradation mode (1 = active)",
    ["mode"],

circuit_breaker_state = Gauge(
    "retrieval_circuit_breaker_state",
    "Circuit breaker state (0=closed, 1=open, 2=half_open)",
    ["component"],
)

degraded_searches_total = Counter(
    "retrieval_degraded_searches_total",
    "Total searches in degraded mode",
    ["mode"],
)

def update_degradation_metrics(manager: RetrievalDegradationManager) -> None:
    """Update Prometheus metrics from degradation manager."""
    status = manager.get_status()

    # Reset all modes, set active one
    for mode in DegradationMode:
        degradation_mode_gauge.labels(mode=mode.value).set(
            1 if mode == status.mode else 0
        )

    # Circuit breaker states
    state_map = {CircuitState.CLOSED: 0, CircuitState.OPEN: 1, CircuitState.HALF_OPEN: 2}
    circuit_breaker_state.labels(component="qdrant").set(
        state_map[manager.qdrant_breaker.state]
    )
    circuit_breaker_state.labels(component="opensearch").set(
        state_map[manager.opensearch_breaker.state]
    )
    circuit_breaker_state.labels(component="reranker").set(
        state_map[manager.reranker_breaker.state]

    breaker = CircuitBreaker("test", CircuitBreakerConfig(failure_threshold=3))
