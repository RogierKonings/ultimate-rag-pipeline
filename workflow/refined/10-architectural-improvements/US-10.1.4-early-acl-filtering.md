# US-10.1.4: Early ACL Filtering

> **Initiative:** 1 - Multi-Store Indexing & ACL Bulletproofing
> **Priority:** P0
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Move ACL filtering from post-reranking to the database query level, ensuring unauthorized documents never reach the reranker and improving performance.

## Problem Statement

**Current state**: According to [filter.py](services/retrieval/acl/filter.py), ACL filtering is implemented but examination of the retrieval flow in [hybrid.py](services/retrieval/search/hybrid.py) shows:
- Filters are passed to Qdrant and OpenSearch
- However, the ACL filter application timing relative to reranking needs verification
- CLAUDE.md states: "Apply ACL filters AFTER reranking to preserve quality"

**Issues with post-rerank ACL filtering**:
- Performance: Reranker processes unauthorized documents unnecessarily
- Resource waste: Embedding comparisons on docs user can't see
- Edge case risk: If reranker returns exactly `top_k` unauthorized docs, user sees empty results
- Latency: More documents through expensive reranker

**Proposed change**: Apply ACL filters at the query level (before fusion/reranking) while maintaining retrieval quality.

## User Story

**As a** security-conscious developer
**I want** ACL filters applied at the database query level
**So that** unauthorized documents never reach the reranker

## Acceptance Criteria

### AC-1: Query-Level ACL Filtering
- [ ] Qdrant queries ALWAYS include `tenant_id`, `visibility`, `allowed_groups` filters
- [ ] OpenSearch queries include equivalent filter clauses
- [ ] Filters applied before results returned from stores
- [ ] ACL filter construction extracted to reusable utility

### AC-2: Safety Net Filter (Defense in Depth)
- [ ] Post-rerank ACL filter retained as safety net only
- [ ] Safety net logs warning if it filters anything (indicates bug)
- [ ] Metric: `acl_safety_net_filtered_total` (should be zero)

### AC-3: Performance Validation
- [ ] Measure retrieval latency before and after
- [ ] Fewer documents processed by reranker (measure reduction)
- [ ] P95 latency improvement documented

### AC-4: Security Validation
- [ ] Integration test: unauthorized docs never appear at any stage
- [ ] Test all visibility levels: public, private, group, tenant
- [ ] Test edge case: user with no group memberships
- [ ] Test edge case: admin bypass

# services/retrieval/search/semantic.py

from retrieval.acl.filter import ACLFilter, UserContext

class SemanticSearcher:
    def __init__(self, qdrant_client: QdrantClient, acl_filter: ACLFilter):
        self.qdrant = qdrant_client
        self.acl_filter = acl_filter

    async def search(
        self,
        query_embedding: list[float],
        user_context: UserContext,
        top_k: int = 50,
        additional_filters: dict | None = None,
    ) -> list[SearchResult]:
        """
        Semantic search with mandatory ACL filtering.

        ACL filters are ALWAYS applied - this is not optional.
        """
        # Build ACL filter - MANDATORY
        acl_filter = self.acl_filter.build_qdrant_filter(user_context)

        # Merge with any additional filters
        combined_filter = self._merge_filters(acl_filter, additional_filters)

        # Query Qdrant with filter
        results = await self.qdrant.query_points(
            collection_name=self.collection_name,
            query=query_embedding,
            query_filter=combined_filter,  # ACL filter always applied here
            limit=top_k,
            with_payload=True,
        )

        return [self._to_search_result(r) for r in results.points]

    def _merge_filters(
        self,
        acl_filter: Filter,
        additional: dict | None,
    ) -> Filter:
        """Merge ACL filter with additional filters."""
        if not additional:
            return acl_filter

        # ACL conditions go in 'must' - they're mandatory
        # Additional filters merged appropriately
        return Filter(
            must=[
                *acl_filter.must,
                *self._dict_to_conditions(additional),
            ]
        )

### Enhanced ACL Filter with Status

```python
# services/retrieval/acl/filter.py - enhanced version

from qdrant_client.models import Filter, FieldCondition, MatchValue, MatchAny

class ACLFilter:
    """
    Builds ACL filters for Qdrant and OpenSearch.

    IMPORTANT: These filters must ALWAYS be applied to queries.
    They enforce:
    1. Tenant isolation (mandatory)
    2. Document status (only active documents)
    3. Visibility rules (public/private/group/tenant)
    4. User-specific access (allowed_users, denied_users)
    """

    def build_qdrant_filter(self, user_context: UserContext) -> Filter:
        """
        Build Qdrant filter from user context.

        This filter is MANDATORY and must be applied to all queries.
        """
        must_conditions = [
            # Tenant isolation - ALWAYS required
            FieldCondition(
                key="tenant_id",
                match=MatchValue(value=str(user_context.tenant_id)),
            ),
            # Only active documents - ALWAYS required
            FieldCondition(
                key="status",
                match=MatchValue(value="active"),
            ),
        ]

        # Visibility-based access
        visibility_conditions = self._build_visibility_conditions_qdrant(user_context)

        return Filter(
            must=must_conditions,
            should=visibility_conditions,
            must_not=self._build_denied_conditions_qdrant(user_context),
        )

    def _build_visibility_conditions_qdrant(
        self,
        user_context: UserContext,
    ) -> list[FieldCondition]:
        """Build visibility-based access conditions."""
        conditions = [
            # Public documents - visible to all in tenant
            FieldCondition(
                key="visibility",
                match=MatchValue(value="public"),
            ),
            # Tenant-wide documents
            FieldCondition(
                key="visibility",
                match=MatchValue(value="tenant"),
            ),
        ]

        # Group-based access
        if user_context.groups:
            conditions.append(
                Filter(
                    must=[
                        FieldCondition(
                            key="visibility",
                            match=MatchValue(value="group"),
                        ),
                        FieldCondition(
                            key="allowed_groups",
                            match=MatchAny(any=user_context.groups),
                        ),
                    ]
                )
            )

        # Private documents owned by user
        if user_context.user_id:
            conditions.append(
                Filter(
                    must=[
                        FieldCondition(
                            key="visibility",
                            match=MatchValue(value="private"),
                        ),
                        FieldCondition(
                            key="owner_id",
                            match=MatchValue(value=str(user_context.user_id)),
                        ),
                    ]
                )
            )

            # Explicit user allowlist
            conditions.append(
                FieldCondition(
                    key="allowed_users",
                    match=MatchAny(any=[str(user_context.user_id)]),
                )
            )

        return conditions

    def build_opensearch_filter(self, user_context: UserContext) -> dict:
        """
        Build OpenSearch bool query filter.

        This filter is MANDATORY and must be applied to all queries.
        """
        filter_clauses = [
            # Tenant isolation
            {"term": {"tenant_id": str(user_context.tenant_id)}},
            # Only active documents
            {"term": {"status": "active"}},
        ]

        # Visibility-based access (should = OR)
        visibility_should = [
            {"term": {"visibility": "public"}},
            {"term": {"visibility": "tenant"}},
        ]

        if user_context.groups:
            visibility_should.append({
                "bool": {
                    "must": [
                        {"term": {"visibility": "group"}},
                        {"terms": {"allowed_groups": user_context.groups}},
                    ]
                }
            })

        if user_context.user_id:
            visibility_should.append({
                "bool": {
                    "must": [
                        {"term": {"visibility": "private"}},
                        {"term": {"owner_id": str(user_context.user_id)}},
                    ]
                }
            })
            visibility_should.append({
                "terms": {"allowed_users": [str(user_context.user_id)]}
            })

        # Denied access (must_not)
        must_not = []
        if user_context.groups:
            must_not.append({
                "terms": {"denied_groups": user_context.groups}
            })
        if user_context.user_id:
            must_not.append({
                "terms": {"denied_users": [str(user_context.user_id)]}
            })

        return {
            "bool": {
                "filter": filter_clauses,
                "should": visibility_should,
                "minimum_should_match": 1,
                "must_not": must_not,
            }
        }
```

### Safety Net Filter (Post-Rerank)

```python
# services/retrieval/acl/safety_net.py

from prometheus_client import Counter
import structlog

logger = structlog.get_logger(__name__)

acl_safety_net_filtered = Counter(
    "acl_safety_net_filtered_total",
    "Documents filtered by safety net (should be zero)",
    ["tenant_id", "reason"],
)

class ACLSafetyNet:
    """
    Defense-in-depth filter applied after reranking.

    This should NEVER filter anything if query-level ACL is working.
    Any filtering here indicates a bug and is logged as a warning.
    """

    def filter(
        self,
        results: list[SearchResult],
        user_context: UserContext,
    ) -> list[SearchResult]:
        """
        Apply safety net ACL filter.

        Returns filtered results and logs warnings for any filtering.
        """
        filtered = []
        for result in results:
            if self._is_accessible(result, user_context):
                filtered.append(result)
            else:
                # This should NEVER happen - log warning
                logger.warning(
                    "acl_safety_net_filtered",
                    document_id=result.document_id,
                    chunk_id=result.chunk_id,
                    tenant_id=user_context.tenant_id,
                    visibility=result.visibility,
                    reason="safety_net_catch",
                )
                acl_safety_net_filtered.labels(
                    tenant_id=user_context.tenant_id,
                    reason="unauthorized_access_attempt",
                ).inc()

        return filtered

    def _is_accessible(
        self,
        result: SearchResult,
        user_context: UserContext,
    ) -> bool:
        """Check if result is accessible to user."""
        # Tenant check
        if result.tenant_id != user_context.tenant_id:
            return False

        # Status check
        if result.status != "active":
            return False

        # Visibility checks
        if result.visibility == "public":
            return True
        if result.visibility == "tenant":
            return True
        if result.visibility == "group":
            return bool(
                set(result.allowed_groups or []) &
                set(user_context.groups or [])
            )
        if result.visibility == "private":
            return result.owner_id == str(user_context.user_id)

        return False
```

### Retrieval Pipeline Integration

```python
# services/retrieval/search/hybrid.py

class HybridSearcher:
    async def search(
        self,
        query: str,
        user_context: UserContext,
        options: SearchOptions,
    ) -> HybridSearchResult:
        """
        Hybrid search with early ACL filtering.

        ACL filters are applied at query level (semantic + keyword).
        Safety net filter applied post-rerank as defense-in-depth.
        """
        # Preprocess query
        processed = await self.preprocessor.process(query)

        # Parallel search with ACL filters (applied inside each searcher)
        semantic_task = self.semantic_searcher.search(
            query_embedding=processed.embedding,
            user_context=user_context,  # ACL filter built from this
            top_k=options.semantic_top_k,
        )
        keyword_task = self.keyword_searcher.search(
            query=processed.expanded_query,
            user_context=user_context,  # ACL filter built from this
            top_k=options.keyword_top_k,
        )

        semantic_results, keyword_results = await asyncio.gather(
            semantic_task, keyword_task
        )

        # Fusion (RRF)
        fused = self.fusion.fuse(semantic_results, keyword_results, options)

        # Reranking (all docs should already be authorized)
        if options.use_reranker:
            reranked = await self.reranker.rerank(
                query=query,
                results=fused,
                top_k=options.rerank_top_k,
            )
        else:
            reranked = fused[:options.final_top_k]

        # Safety net filter (should be no-op)
        final = self.safety_net.filter(reranked, user_context)

        return HybridSearchResult(
            results=final,
            debug={
                "semantic_count": len(semantic_results),
                "keyword_count": len(keyword_results),
                "fused_count": len(fused),
                "reranked_count": len(reranked),
                "final_count": len(final),
                "safety_net_filtered": len(reranked) - len(final),
            },
        )
```

async def test_semantic_search_applies_acl_filter(mock_qdrant):
    """Semantic search must apply ACL filter to Qdrant query."""
    searcher = SemanticSearcher(mock_qdrant, ACLFilter())
    user_context = UserContext(tenant_id="t1", user_id="u1", groups=["g1"])

async def test_safety_net_logs_warning_on_filter(caplog):
    """Safety net should log warning if it filters anything."""
    safety_net = ACLSafetyNet()
    user_context = UserContext(tenant_id="t1", user_id="u1", groups=[])

    # Result with wrong tenant (shouldn't happen)
    bad_result = SearchResult(
        document_id="d1",
        tenant_id="t2",  # Wrong tenant!

    with caplog.at_level(logging.WARNING):

    assert "acl_safety_net_filtered" in caplog.text
