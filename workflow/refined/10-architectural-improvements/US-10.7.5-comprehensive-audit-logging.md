# US-10.7.5: Comprehensive Audit Logging

> **Initiative:** 7 - Security & Production Hardening
> **Priority:** P1
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Implement comprehensive audit logging for all data access, modifications, and administrative actions to meet compliance requirements.

## Problem Statement

**Current state**: Logging is operational, not audit-focused:
- No structured audit trail
- Missing who/what/when/why context
- Logs scattered across services
- No tamper-evident storage
- Cannot reconstruct access history

**Impact**:
- Compliance failures (SOC2, HIPAA, GDPR)
- Cannot investigate security incidents
- No accountability for data access
- Audit requests require manual work

## User Story

**As a** compliance officer
**I want** comprehensive audit logs
**So that** I can demonstrate compliance and investigate incidents

## Acceptance Criteria

### AC-1: Data Access Logging
- [ ] Log all document reads with user context
- [ ] Log all search queries with results count
- [ ] Log all data exports
- [ ] Include tenant, user, timestamp, action

### AC-2: Data Modification Logging
- [ ] Log document creates/updates/deletes
- [ ] Log chunk modifications
- [ ] Log configuration changes
- [ ] Include before/after for changes

### AC-3: Administrative Action Logging
- [ ] Log user/tenant management
- [ ] Log permission changes
- [ ] Log configuration updates
- [ ] Log service restarts/deployments

### AC-4: Audit Log Storage
- [ ] Immutable/append-only storage
- [ ] Configurable retention
- [ ] Encrypted at rest
- [ ] Queryable for investigations

### AC-5: Audit API
- [ ] Query audit logs by entity/user/time
- [ ] Export audit reports
- [ ] Real-time audit streaming

### Audit Logger Implementation

```python
# services/shared/audit/logger.py

import hashlib
import hmac
import json
from datetime import datetime
from typing import Any, Optional
import structlog
from fastapi import Request

from .models import AuditEvent, AuditAction, AuditResource, AuditOutcome

logger = structlog.get_logger()

class AuditLogger:
    """
    Central audit logging facility.

    Features:
    - Structured audit events
    - HMAC signatures for tamper detection
    - Multiple output backends
    - Correlation with request context
    """

    def __init__(
        self,
        service_name: str,
        signing_key: Optional[bytes] = None,
        backends: list["AuditBackend"] = None,
    ):
        self.service_name = service_name
        self.signing_key = signing_key
        self.backends = backends or []

    async def log(
        self,
        action: AuditAction,
        resource_type: AuditResource,
        tenant_id: str,
        outcome: AuditOutcome = AuditOutcome.SUCCESS,
        user_id: Optional[str] = None,
        resource_id: Optional[str] = None,
        resource_name: Optional[str] = None,
        details: Optional[dict] = None,
        changes: Optional[dict] = None,
        request: Optional[Request] = None,
        outcome_reason: Optional[str] = None,
    ):
        """Log an audit event."""

        # Build event
        event = AuditEvent(
            tenant_id=tenant_id,
            user_id=user_id,
            service_name=self.service_name,
            action=action,
            resource_type=resource_type,
            resource_id=resource_id,
            resource_name=resource_name,
            outcome=outcome,
            outcome_reason=outcome_reason,
            details=details or {},
            changes=changes,
        )

        # Add request context
        if request:
            event.ip_address = self._get_client_ip(request)
            event.user_agent = request.headers.get("User-Agent")
            event.request_id = request.headers.get("X-Request-ID")
            event.correlation_id = request.headers.get("X-Correlation-ID")

            # Get user from request state if available
            if hasattr(request.state, "user"):
                event.user_id = event.user_id or request.state.user.id
                event.user_email = request.state.user.email

        # Sign event
        if self.signing_key:
            event.signature = self._sign_event(event)

        # Send to backends
        for backend in self.backends:
            try:
                await backend.write(event)
            except Exception as e:
                logger.error(
                    "audit_backend_write_failed",
                    backend=backend.__class__.__name__,
                    error=str(e),
                )

        # Also log to standard logger
        logger.info(
            "audit_event",
            event_id=event.event_id,
            action=event.action.value,
            resource_type=event.resource_type.value,
            resource_id=event.resource_id,
            tenant_id=event.tenant_id,
            user_id=event.user_id,
            outcome=event.outcome.value,
        )

    def _sign_event(self, event: AuditEvent) -> str:
        """Create HMAC signature for tamper detection."""
        # Create canonical representation
        canonical = json.dumps(
            {
                "event_id": event.event_id,
                "timestamp": event.timestamp.isoformat(),
                "tenant_id": event.tenant_id,
                "user_id": event.user_id,
                "action": event.action.value,
                "resource_type": event.resource_type.value,
                "resource_id": event.resource_id,
                "outcome": event.outcome.value,
            },
            sort_keys=True,
        )

        return hmac.new(
            self.signing_key,
            canonical.encode(),
            hashlib.sha256,
        ).hexdigest()

    def _get_client_ip(self, request: Request) -> str:
        """Extract client IP from request headers."""
        # Check proxy headers
        forwarded = request.headers.get("X-Forwarded-For")
        if forwarded:
            return forwarded.split(",")[0].strip()

        real_ip = request.headers.get("X-Real-IP")
        if real_ip:
            return real_ip

        return request.client.host if request.client else "unknown"

    # Convenience methods
    async def log_read(
        self,
        resource_type: AuditResource,
        resource_id: str,
        tenant_id: str,
        **kwargs,
    ):
        """Log a read access."""
        await self.log(
            action=AuditAction.READ,
            resource_type=resource_type,
            resource_id=resource_id,
            tenant_id=tenant_id,
            **kwargs,
        )

    async def log_search(
        self,
        tenant_id: str,
        query: str,
        results_count: int,
        **kwargs,
    ):
        """Log a search query."""
        await self.log(
            action=AuditAction.SEARCH,
            resource_type=AuditResource.QUERY,
            tenant_id=tenant_id,
            details={"query": query, "results_count": results_count},
            **kwargs,
        )

    async def log_create(
        self,
        resource_type: AuditResource,
        resource_id: str,
        tenant_id: str,
        **kwargs,
    ):
        """Log a create action."""
        await self.log(
            action=AuditAction.CREATE,
            resource_type=resource_type,
            resource_id=resource_id,
            tenant_id=tenant_id,
            **kwargs,
        )

    async def log_update(
        self,
        resource_type: AuditResource,
        resource_id: str,
        tenant_id: str,
        before: dict,
        after: dict,
        **kwargs,
    ):
        """Log an update with before/after."""
        await self.log(
            action=AuditAction.UPDATE,
            resource_type=resource_type,
            resource_id=resource_id,
            tenant_id=tenant_id,
            changes={"before": before, "after": after},
            **kwargs,
        )

    async def log_delete(
        self,
        resource_type: AuditResource,
        resource_id: str,
        tenant_id: str,
        **kwargs,
    ):
        """Log a delete action."""
        await self.log(
            action=AuditAction.DELETE,
            resource_type=resource_type,
            resource_id=resource_id,
            tenant_id=tenant_id,
            **kwargs,
        )
```

```python
from abc import ABC, abstractmethod
from datetime import datetime, timedelta
from typing import AsyncIterator, Optional
import json
from sqlalchemy import select, and_
from opensearchpy import AsyncOpenSearch

from .models import AuditEvent, AuditAction, AuditResource

class AuditBackend(ABC):
    """Abstract base for audit storage backends."""

    @abstractmethod
    async def write(self, event: AuditEvent):
        """Write an audit event."""
        pass

    @abstractmethod
    async def query(
        self,
        tenant_id: str,
        start_time: Optional[datetime] = None,
        end_time: Optional[datetime] = None,
        user_id: Optional[str] = None,
        action: Optional[AuditAction] = None,
        resource_type: Optional[AuditResource] = None,
        resource_id: Optional[str] = None,
        limit: int = 100,
        offset: int = 0,
    ) -> list[AuditEvent]:
        """Query audit events."""
        pass


class PostgresAuditBackend(AuditBackend):
    """PostgreSQL-backed audit storage."""

    def __init__(self, session_factory):
        self.session_factory = session_factory

    async def write(self, event: AuditEvent):
        """Write audit event to PostgreSQL."""
        from shared.database.models import AuditLog

        async with self.session_factory() as session:
            record = AuditLog(
                event_id=event.event_id,
                timestamp=event.timestamp,
                tenant_id=event.tenant_id,
                user_id=event.user_id,
                user_email=event.user_email,
                service_name=event.service_name,
                ip_address=event.ip_address,
                action=event.action.value,
                resource_type=event.resource_type.value,
                resource_id=event.resource_id,
                resource_name=event.resource_name,
                outcome=event.outcome.value,
                outcome_reason=event.outcome_reason,
                details=event.details,
                changes=event.changes,
                signature=event.signature,
                request_id=event.request_id,
                correlation_id=event.correlation_id,
            )
            session.add(record)
            await session.commit()

    async def query(
        self,
        tenant_id: str,
        start_time: Optional[datetime] = None,
        end_time: Optional[datetime] = None,
        user_id: Optional[str] = None,
        action: Optional[AuditAction] = None,
        resource_type: Optional[AuditResource] = None,
        resource_id: Optional[str] = None,
        limit: int = 100,
        offset: int = 0,
    ) -> list[AuditEvent]:
        """Query audit events from PostgreSQL."""
        from shared.database.models import AuditLog

        async with self.session_factory() as session:
            query = select(AuditLog).where(AuditLog.tenant_id == tenant_id)

            if start_time:
                query = query.where(AuditLog.timestamp >= start_time)
            if end_time:
                query = query.where(AuditLog.timestamp <= end_time)
            if user_id:
                query = query.where(AuditLog.user_id == user_id)
            if action:
                query = query.where(AuditLog.action == action.value)
            if resource_type:
                query = query.where(AuditLog.resource_type == resource_type.value)
            if resource_id:
                query = query.where(AuditLog.resource_id == resource_id)

            query = query.order_by(AuditLog.timestamp.desc())
            query = query.offset(offset).limit(limit)

            result = await session.execute(query)
            records = result.scalars().all()

            return [self._record_to_event(r) for r in records]

    def _record_to_event(self, record) -> AuditEvent:
        """Convert database record to AuditEvent."""
        return AuditEvent(
            event_id=record.event_id,
            timestamp=record.timestamp,
            tenant_id=record.tenant_id,
            user_id=record.user_id,
            user_email=record.user_email,
            service_name=record.service_name,
            ip_address=record.ip_address,
            action=AuditAction(record.action),
            resource_type=AuditResource(record.resource_type),
            resource_id=record.resource_id,
            resource_name=record.resource_name,
            outcome=record.outcome,
            outcome_reason=record.outcome_reason,
            details=record.details,
            changes=record.changes,
            signature=record.signature,
            request_id=record.request_id,
            correlation_id=record.correlation_id,
        )


class OpenSearchAuditBackend(AuditBackend):
    """OpenSearch-backed audit storage for high-volume and search."""

    def __init__(
        self,
        client: AsyncOpenSearch,
        index_prefix: str = "audit",
    ):
        self.client = client
        self.index_prefix = index_prefix

    def _get_index_name(self, timestamp: datetime) -> str:
        """Get index name for timestamp (daily indices)."""
        return f"{self.index_prefix}-{timestamp.strftime('%Y.%m.%d')}"

    async def write(self, event: AuditEvent):
        """Write audit event to OpenSearch."""
        index_name = self._get_index_name(event.timestamp)

        await self.client.index(
            index=index_name,
            id=event.event_id,
            body=event.dict(),
        )

    async def query(
        self,
        tenant_id: str,
        start_time: Optional[datetime] = None,
        end_time: Optional[datetime] = None,
        user_id: Optional[str] = None,
        action: Optional[AuditAction] = None,
        resource_type: Optional[AuditResource] = None,
        resource_id: Optional[str] = None,
        limit: int = 100,
        offset: int = 0,
    ) -> list[AuditEvent]:
        """Query audit events from OpenSearch."""
        # Build query
        must = [{"term": {"tenant_id": tenant_id}}]

        if start_time or end_time:
            range_query = {"range": {"timestamp": {}}}
            if start_time:
                range_query["range"]["timestamp"]["gte"] = start_time.isoformat()
            if end_time:
                range_query["range"]["timestamp"]["lte"] = end_time.isoformat()
            must.append(range_query)

        if user_id:
            must.append({"term": {"user_id": user_id}})
        if action:
            must.append({"term": {"action": action.value}})
        if resource_type:
            must.append({"term": {"resource_type": resource_type.value}})
        if resource_id:
            must.append({"term": {"resource_id": resource_id}})

        body = {
            "query": {"bool": {"must": must}},
            "sort": [{"timestamp": {"order": "desc"}}],
            "from": offset,
            "size": limit,
        }

        # Search across all audit indices
        response = await self.client.search(
            index=f"{self.index_prefix}-*",
            body=body,
        )

        return [
            AuditEvent(**hit["_source"])
            for hit in response["hits"]["hits"]
        ]


class S3AuditBackend(AuditBackend):
    """S3-backed audit storage for long-term retention."""

    def __init__(
        self,
        client,  # boto3 S3 client
        bucket: str,
        prefix: str = "audit",
    ):
        self.client = client
        self.bucket = bucket
        self.prefix = prefix
        self._buffer: list[AuditEvent] = []
        self._buffer_size = 100

    async def write(self, event: AuditEvent):
        """Buffer and write audit events to S3."""
        self._buffer.append(event)

        if len(self._buffer) >= self._buffer_size:
            await self._flush()

    async def _flush(self):
        """Flush buffer to S3."""
        if not self._buffer:
            return

        timestamp = datetime.utcnow()
        key = f"{self.prefix}/{timestamp.strftime('%Y/%m/%d/%H')}/{timestamp.timestamp()}.json"

        body = json.dumps([e.dict() for e in self._buffer], default=str)

        self.client.put_object(
            Bucket=self.bucket,
            Key=key,
            Body=body.encode(),
            ContentType="application/json",
        )

        self._buffer = []

    async def query(self, **kwargs) -> list[AuditEvent]:
        """S3 backend doesn't support direct queries."""
        raise NotImplementedError("Use OpenSearch or PostgreSQL for queries")
```

```python
@router.get("/export")
async def export_audit_logs(
    tenant_id: str,
    start_time: datetime,
    end_time: datetime,
    format: str = Query(default="json", regex="^(json|csv)$"),
    audit_backend: AuditBackend = Depends(get_audit_backend),
    current_user = Depends(get_current_user),
):
    """
    Export audit logs for compliance reporting.

    Returns streamed JSON or CSV.
    """
    if not current_user.has_permission("audit:export", tenant_id):
        raise HTTPException(status_code=403, detail="Audit export permission required")

    # Validate time range (max 90 days)
    if (end_time - start_time).days > 90:
        raise HTTPException(
            status_code=400,
            detail="Export time range cannot exceed 90 days",
        )

    events = await audit_backend.query(
        tenant_id=tenant_id,
        start_time=start_time,
        end_time=end_time,
        limit=10000,  # Large limit for export
    )

    if format == "csv":
        return _events_to_csv(events)
    else:
        return {"events": [e.dict() for e in events]}

def _events_to_csv(events: list[AuditEvent]) -> str:
    """Convert events to CSV format."""
    import csv
    import io

    output = io.StringIO()
    writer = csv.writer(output)

    # Header
    writer.writerow([
        "event_id", "timestamp", "tenant_id", "user_id", "action",
        "resource_type", "resource_id", "outcome", "ip_address",
    ])

    for event in events:
        writer.writerow([
            event.event_id,
            event.timestamp.isoformat(),
            event.tenant_id,
            event.user_id,
            event.action.value,
            event.resource_type.value,
            event.resource_id,
            event.outcome.value,
            event.ip_address,
        ])

    return output.getvalue()
```

```python
# services/shared/audit/middleware.py

from fastapi import Request, Response
from starlette.middleware.base import BaseHTTPMiddleware
import time

from .logger import AuditLogger
from .models import AuditAction, AuditResource, AuditOutcome

class AuditMiddleware(BaseHTTPMiddleware):
    """Middleware to automatically audit API requests."""

    def __init__(
        self,
        app,
        audit_logger: AuditLogger,
        exclude_paths: list[str] = None,
    ):
        super().__init__(app)
        self.audit_logger = audit_logger
        self.exclude_paths = exclude_paths or [
            "/health",
            "/metrics",
            "/docs",
            "/openapi.json",
        ]

    async def dispatch(self, request: Request, call_next):
        # Skip excluded paths
        if any(request.url.path.startswith(p) for p in self.exclude_paths):
            return await call_next(request)

        start_time = time.time()
        response = None
        outcome = AuditOutcome.SUCCESS

        try:
            response = await call_next(request)

            if response.status_code >= 400:
                if response.status_code == 403:
                    outcome = AuditOutcome.DENIED
                elif response.status_code >= 500:
                    outcome = AuditOutcome.ERROR
                else:
                    outcome = AuditOutcome.FAILURE

            return response

        except Exception as e:
            outcome = AuditOutcome.ERROR
            raise

        finally:
            # Extract context from request
            tenant_id = self._get_tenant_id(request)
            action, resource_type, resource_id = self._parse_request(request)

            if tenant_id and action:
                await self.audit_logger.log(
                    action=action,
                    resource_type=resource_type,
                    resource_id=resource_id,
                    tenant_id=tenant_id,
                    outcome=outcome,
                    request=request,
                    details={
                        "method": request.method,
                        "path": request.url.path,
                        "status_code": response.status_code if response else 500,
                        "latency_ms": (time.time() - start_time) * 1000,
                    },
                )

    def _get_tenant_id(self, request: Request) -> str | None:
        """Extract tenant ID from request."""
        # From header
        tenant_id = request.headers.get("X-Tenant-ID")
        if tenant_id:
            return tenant_id

        # From path parameter
        if hasattr(request.state, "tenant_id"):
            return request.state.tenant_id

        # From query parameter
        return request.query_params.get("tenant_id")

    def _parse_request(self, request: Request) -> tuple:
        """Parse request to determine action and resource."""
        path = request.url.path
        method = request.method

        # Map HTTP methods to audit actions
        method_to_action = {
            "GET": AuditAction.READ,
            "POST": AuditAction.CREATE,
            "PUT": AuditAction.UPDATE,
            "PATCH": AuditAction.UPDATE,
            "DELETE": AuditAction.DELETE,
        }

        action = method_to_action.get(method, AuditAction.READ)

        # Parse resource from path
        # /api/v1/documents/{id} -> DOCUMENT, {id}
        # /api/v1/query -> QUERY, None

        if "/documents" in path:
            resource_type = AuditResource.DOCUMENT
        elif "/query" in path:
            resource_type = AuditResource.QUERY
            action = AuditAction.SEARCH
        elif "/users" in path:
            resource_type = AuditResource.USER
        elif "/tenants" in path:
            resource_type = AuditResource.TENANT
        else:
            resource_type = AuditResource.CONFIG

        # Extract resource ID from path
        resource_id = self._extract_resource_id(path)

        return action, resource_type, resource_id

    def _extract_resource_id(self, path: str) -> str | None:
        """Extract resource ID from path."""
        import re

        # Match UUID or ID patterns
        patterns = [
            r"/documents/([a-f0-9-]{36})",
            r"/users/([a-f0-9-]{36})",
            r"/tenants/([a-z0-9-]+)",
        ]

        for pattern in patterns:
            match = re.search(pattern, path)
            if match:
                return match.group(1)

        return None
```
