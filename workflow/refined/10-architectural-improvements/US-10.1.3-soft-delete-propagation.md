# US-10.1.3: Soft-Delete Propagation

> **Initiative:** 1 - Multi-Store Indexing & ACL Bulletproofing
> **Priority:** P0
> **Effort:** Small (1-2 days)
> **Status:** Draft

## Summary

Ensure document deletions in PostgreSQL cascade immediately to Qdrant and OpenSearch, preventing deleted content from appearing in search results.

## Problem Statement

**Current state**: The `Document` model in [document.py](services/shared/database/models/document.py) uses `SoftDeleteMixin` which sets `status='deleted'` and `deleted_at` timestamp. However:

- Deletion only updates PostgreSQL
- Vectors remain in Qdrant until manually removed
- Documents remain in OpenSearch
- No automatic propagation mechanism exists

**Impact**:
- Deleted documents may still appear in search results
- Privacy/compliance violations if sensitive documents aren't fully removed
- Inconsistent state between stores
- Manual cleanup required

## User Story

**As a** system administrator
**I want** document deletions to cascade to all stores atomically
**So that** deleted content is never returned in search results

## Acceptance Criteria

### AC-1: Tombstone Task Implementation
- [ ] New Celery task `propagate_deletion(document_id, tenant_id)`
- [ ] Deletes all chunks from Qdrant by `document_id`
- [ ] Deletes all chunks from OpenSearch by `document_id`
- [ ] Runs on high-priority queue for immediate execution
- [ ] Idempotent - safe to retry

### AC-2: Automatic Triggering
- [ ] Setting `status='deleted'` in PostgreSQL triggers tombstone task
- [ ] Uses SQLAlchemy event listener or database trigger
- [ ] Task enqueued within same transaction or immediately after commit

### AC-3: Retrieval Safety Net
- [ ] All retrieval queries include `status='active'` filter
- [ ] Qdrant queries filter by `status` payload field
- [ ] OpenSearch queries filter by `status` field
- [ ] `status` field synced to both stores during indexing

### AC-4: Verification
- [ ] Integration test confirms deleted docs never returned
- [ ] Test covers race condition (query during deletion)
- [ ] Audit log entry for each deletion propagation

### Tombstone Task

```python
# services/ingestion/tasks/tombstone.py

from celery import shared_task
from shared.vectorstore.qdrant_client import QdrantClient
from shared.search.opensearch_client import OpenSearchClient
import structlog

logger = structlog.get_logger(__name__)

@shared_task(
    queue="ingestion",  # High priority queue
    bind=True,
    max_retries=3,
    default_retry_delay=5,
    autoretry_for=(Exception,),
)
async def propagate_deletion(
    self,
    document_id: str,
    tenant_id: str,
) -> dict:
    """
    Propagate document deletion to all external stores.

    This task is idempotent - safe to retry on failure.
    Deletes are by document_id, so partial failures are recoverable.

    Args:
        document_id: UUID of the deleted document
        tenant_id: Tenant ID for scoping

    Returns:
        Summary of deletion operations
    """
    logger.info(
        "deletion_propagation_started",
        document_id=document_id,
        tenant_id=tenant_id,
    )

    result = {
        "document_id": document_id,
        "tenant_id": tenant_id,
        "qdrant_deleted": 0,
        "opensearch_deleted": 0,
        "errors": [],
    }

    qdrant = QdrantClient()
    opensearch = OpenSearchClient()

    # Delete from Qdrant
    try:
        deleted_count = await qdrant.delete_by_document_id(
            document_id=document_id,
            tenant_id=tenant_id,
        )
        result["qdrant_deleted"] = deleted_count
        logger.info(
            "qdrant_deletion_complete",
            document_id=document_id,
            deleted_count=deleted_count,
        )
    except Exception as e:
        error_msg = f"Qdrant deletion failed: {e}"
        result["errors"].append(error_msg)
        logger.error(
            "qdrant_deletion_failed",
            document_id=document_id,
            error=str(e),
        )

    # Delete from OpenSearch
    try:
        deleted_count = await opensearch.delete_by_document_id(
            document_id=document_id,
            tenant_id=tenant_id,
        )
        result["opensearch_deleted"] = deleted_count
        logger.info(
            "opensearch_deletion_complete",
            document_id=document_id,
            deleted_count=deleted_count,
        )
    except Exception as e:
        error_msg = f"OpenSearch deletion failed: {e}"
        result["errors"].append(error_msg)
        logger.error(
            "opensearch_deletion_failed",
            document_id=document_id,
            error=str(e),
        )

    # If any errors, raise to trigger retry
    if result["errors"]:
        raise Exception("; ".join(result["errors"]))

    logger.info(
        "deletion_propagation_complete",
        document_id=document_id,
        qdrant_deleted=result["qdrant_deleted"],
        opensearch_deleted=result["opensearch_deleted"],
    )

    return result
```

### SQLAlchemy Event Listener

```python
# services/shared/database/models/document.py

from sqlalchemy import event
from sqlalchemy.orm import Session

@event.listens_for(Document, "after_update")
def on_document_update(mapper, connection, target: Document):
    """Trigger deletion propagation when document is soft-deleted."""
    from sqlalchemy.orm.attributes import get_history

    # Check if status changed to 'deleted'
    status_history = get_history(target, "status")
    if status_history.has_changes():
        old_status = status_history.deleted[0] if status_history.deleted else None
        new_status = status_history.added[0] if status_history.added else None

        if old_status != "deleted" and new_status == "deleted":
            # Enqueue tombstone task after commit
            # Use after_commit hook to ensure transaction completes
            @event.listens_for(Session, "after_commit", once=True)
            def after_commit(session):
                from ingestion.tasks.tombstone import propagate_deletion
                propagate_deletion.delay(
                    document_id=str(target.id),
                    tenant_id=target.tenant_id,
                )
```

def upgrade():
    # Create function to notify on deletion
    op.execute("""
        CREATE OR REPLACE FUNCTION notify_document_deletion()
        RETURNS TRIGGER AS $$
        BEGIN
            IF OLD.status != 'deleted' AND NEW.status = 'deleted' THEN
                PERFORM pg_notify(
                    'document_deleted',
                    json_build_object(
                        'document_id', NEW.id::text,
                        'tenant_id', NEW.tenant_id
                    )::text
                );
            END IF;
            RETURN NEW;
        END;
        $$ LANGUAGE plpgsql;

        CREATE TRIGGER document_deletion_trigger
        AFTER UPDATE ON source_documents
        FOR EACH ROW
        EXECUTE FUNCTION notify_document_deletion();
    """)

def downgrade():
    op.execute("""
        DROP TRIGGER IF EXISTS document_deletion_trigger ON source_documents;
        DROP FUNCTION IF EXISTS notify_document_deletion();
    """)
```

# services/shared/vectorstore/qdrant_client.py

async def delete_by_document_id(
    self,
    document_id: str,
    tenant_id: str,
) -> int:
    """
    Delete all vectors for a document.

    Args:
        document_id: Document UUID
        tenant_id: Tenant ID for safety

    Returns:
        Number of points deleted
    """
    # First count existing points
    count_before = await self._count_points(document_id, tenant_id)

    # Delete by filter
    await self.client.delete(
        collection_name=self.collection_name,
        points_selector=models.FilterSelector(
            filter=models.Filter(
                must=[
                    models.FieldCondition(
                        key="document_id",
                        match=models.MatchValue(value=document_id),
                    ),
                    models.FieldCondition(
                        key="tenant_id",
                        match=models.MatchValue(value=tenant_id),
                    ),
                ]
            )
        ),
    )

    return count_before


# services/shared/search/opensearch_client.py

async def delete_by_document_id(
    self,
    document_id: str,
    tenant_id: str,
) -> int:
    """
    Delete all documents for a document ID.

    Args:
        document_id: Document UUID
        tenant_id: Tenant ID for safety

    Returns:
        Number of documents deleted
    """
    response = await self.client.delete_by_query(
        index=self.index_name,
        body={
            "query": {
                "bool": {
                    "must": [
                        {"term": {"document_id": document_id}},
                        {"term": {"tenant_id": tenant_id}},
                    ]
                }
            }
        },
        refresh=True,  # Make deletion immediately visible
    )

    return response.get("deleted", 0)
```

async def test_deleted_document_not_returned_in_search(
    db_session, qdrant_client, opensearch_client, retrieval_service

    """Deleted documents should never appear in search results."""
    # Create and index document
    doc = await create_and_index_document(db_session)

    doc.status = "deleted"
    doc.deleted_at = datetime.utcnow()
    await db_session.commit()

    # Wait for tombstone task
    await asyncio.sleep(1)

    # Verify not searchable

    assert not any(r.document_id == str(doc.id) for r in results)

async def test_race_condition_query_during_deletion(
    db_session, retrieval_service
):
    """Query in progress during deletion should still respect status filter."""
    doc = await create_and_index_document(db_session)

    # Start deletion (but don't wait)
    doc.status = "deleted"
    await db_session.commit()

    # Immediate query (before tombstone completes)
    results = await retrieval_service.search("test query", tenant_id=doc.tenant_id)

    # Should not return deleted doc due to status filter
    assert not any(r.document_id == str(doc.id) for r in results)
