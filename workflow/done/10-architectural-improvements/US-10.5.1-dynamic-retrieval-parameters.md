# US-10.5.1: Dynamic Retrieval Parameters

> **Initiative:** 5 - Cost-Aware Retrieval & Model Tiering
> **Priority:** P1
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Adjust retrieval parameters (top_k, reranking) dynamically based on query type and tenant tier for cost optimization.

## User Story

**As a** platform operator
**I want** retrieval parameters adjusted based on query type and tenant
**So that** I can optimize cost without sacrificing quality

## Acceptance Criteria

- [ ] Query type influences `semantic_top_k`, `keyword_top_k`, `use_reranker`, `rerank_top_k`
- [ ] Tenant tier configuration: `basic`, `standard`, `premium`
- [ ] Premium tenants get more candidates and reranking
- [ ] Effective parameters logged in response debug
- [ ] Metrics: `retrieval_top_k_used`, `reranker_invocations_total`

## Technical Design

```python
# services/retrieval/config.py

TIER_CONFIGS = {
    "basic": {
        "semantic_top_k": 20,
        "keyword_top_k": 20,
        "use_reranker": False,
        "rerank_top_k": 0,
        "max_context_tokens": 2000,
    },
    "standard": {
        "semantic_top_k": 35,
        "keyword_top_k": 35,
        "use_reranker": True,
        "rerank_top_k": 15,
        "max_context_tokens": 4000,
    },
    "premium": {
        "semantic_top_k": 50,
        "keyword_top_k": 50,
        "use_reranker": True,
        "rerank_top_k": 30,
        "max_context_tokens": 8000,
    },
}

QUERY_TYPE_MODIFIERS = {
    "SIMPLE": {"top_k_multiplier": 0.5, "use_reranker": False},
    "QUESTION": {"top_k_multiplier": 1.0, "use_reranker": True},
    "SEMANTIC": {"top_k_multiplier": 1.2, "use_reranker": True},
    "HYBRID": {"top_k_multiplier": 1.0, "use_reranker": True},
}

def get_effective_params(tenant_tier: str, query_type: str) -> dict:
    """Calculate effective retrieval parameters."""
    base = TIER_CONFIGS.get(tenant_tier, TIER_CONFIGS["standard"])
    modifier = QUERY_TYPE_MODIFIERS.get(query_type, QUERY_TYPE_MODIFIERS["QUESTION"])

    return {
        "semantic_top_k": int(base["semantic_top_k"] * modifier["top_k_multiplier"]),
        "keyword_top_k": int(base["keyword_top_k"] * modifier["top_k_multiplier"]),
        "use_reranker": base["use_reranker"] and modifier["use_reranker"],
        "rerank_top_k": base["rerank_top_k"],
    }
```
