# US-10.7.4: Enhanced PII Handling

> **Initiative:** 7 - Security & Production Hardening
> **Priority:** P1
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Implement PII detection and redaction for documents, queries, and LLM responses to ensure compliance with privacy regulations.

## Problem Statement

**Current state**: No PII handling in the pipeline:
- Documents ingested without PII screening
- Queries may contain PII that gets logged
- LLM responses may expose sensitive data
- No compliance with GDPR, CCPA, HIPAA

**Impact**:
- Privacy regulation violations
- Risk of data breach exposure
- Customer trust issues
- Legal liability

## User Story

**As a** compliance officer
**I want** automatic PII detection and redaction
**So that** the system complies with privacy regulations

## Acceptance Criteria

### AC-1: PII Detection
- [ ] Detect common PII types (SSN, email, phone, credit card, etc.)
- [ ] Support custom PII patterns per tenant
- [ ] Configurable detection confidence threshold
- [ ] Report detected PII in audit logs

### AC-2: Ingestion-Time Redaction
- [ ] Option to redact PII before indexing
- [ ] Option to store PII with encryption
- [ ] Preserve document utility after redaction
- [ ] Maintain redaction mapping for authorized access

### AC-3: Query Sanitization
- [ ] Detect PII in user queries
- [ ] Option to redact before logging
- [ ] Option to reject queries with PII
- [ ] Alert on frequent PII in queries

### AC-4: Response Filtering
- [ ] Scan LLM responses for PII
- [ ] Redact PII in responses
- [ ] Log redaction events
- [ ] Support tenant-specific rules

```python
# services/shared/pii/detector.py

import re
from dataclasses import dataclass
from enum import Enum
from typing import Optional
import spacy
from presidio_analyzer import AnalyzerEngine, RecognizerRegistry
from presidio_analyzer.nlp_engine import NlpEngineProvider

class PIIType(Enum):
    """Supported PII types."""
    EMAIL = "EMAIL_ADDRESS"
    PHONE = "PHONE_NUMBER"
    SSN = "US_SSN"
    CREDIT_CARD = "CREDIT_CARD"
    PERSON = "PERSON"
    LOCATION = "LOCATION"
    DATE_TIME = "DATE_TIME"
    IP_ADDRESS = "IP_ADDRESS"
    IBAN = "IBAN_CODE"
    US_PASSPORT = "US_PASSPORT"
    US_DRIVER_LICENSE = "US_DRIVER_LICENSE"
    MEDICAL_LICENSE = "MEDICAL_LICENSE"
    CUSTOM = "CUSTOM"

@dataclass
class PIIEntity:
    """Detected PII entity."""
    entity_type: PIIType
    text: str
    start: int
    end: int
    score: float
    recognizer: str

@dataclass
class PIIDetectionResult:
    """Result of PII detection."""
    text: str
    entities: list[PIIEntity]
    has_pii: bool
    entity_count: int

class PIIDetector:
    """
    Detect PII in text using Microsoft Presidio.

    Supports:
    - Standard PII types (email, phone, SSN, etc.)
    - Custom patterns per tenant
    - Configurable confidence thresholds
    """

    def __init__(
        self,
        default_threshold: float = 0.5,
        supported_languages: list[str] = None,
    ):
        self.default_threshold = default_threshold
        self.supported_languages = supported_languages or ["en"]

        # Initialize Presidio with spaCy
        nlp_config = {
            "nlp_engine_name": "spacy",
            "models": [{"lang_code": "en", "model_name": "en_core_web_lg"}],
        }

        nlp_engine = NlpEngineProvider(nlp_configuration=nlp_config).create_engine()
        self.analyzer = AnalyzerEngine(
            nlp_engine=nlp_engine,
            supported_languages=self.supported_languages,
        )

        # Custom recognizers registry
        self._custom_recognizers: dict[str, list] = {}

    def add_custom_pattern(
        self,
        tenant_id: str,
        name: str,
        pattern: str,
        entity_type: str = "CUSTOM",
        score: float = 0.85,
    ):
        """Add custom regex pattern for tenant-specific PII."""
        from presidio_analyzer import Pattern, PatternRecognizer

        recognizer = PatternRecognizer(
            supported_entity=entity_type,
            name=f"{tenant_id}_{name}",
            patterns=[Pattern(name=name, regex=pattern, score=score)],
        )

        if tenant_id not in self._custom_recognizers:
            self._custom_recognizers[tenant_id] = []

        self._custom_recognizers[tenant_id].append(recognizer)

    def detect(
        self,
        text: str,
        tenant_id: Optional[str] = None,
        entity_types: Optional[list[PIIType]] = None,
        threshold: Optional[float] = None,
        language: str = "en",
    ) -> PIIDetectionResult:
        """
        Detect PII entities in text.

        Args:
            text: Text to analyze
            tenant_id: Optional tenant for custom patterns
            entity_types: Optional list of entity types to detect
            threshold: Confidence threshold (0-1)
            language: Text language

        Returns:
            PIIDetectionResult with detected entities
        """
        threshold = threshold or self.default_threshold

        # Build entity list
        entities_to_detect = None
        if entity_types:
            entities_to_detect = [e.value for e in entity_types]

        # Add tenant custom recognizers temporarily
        if tenant_id and tenant_id in self._custom_recognizers:
            for recognizer in self._custom_recognizers[tenant_id]:
                self.analyzer.registry.add_recognizer(recognizer)

        try:
            # Run detection
            results = self.analyzer.analyze(
                text=text,
                entities=entities_to_detect,
                language=language,
                score_threshold=threshold,
            )

            # Convert to our format
            entities = [
                PIIEntity(
                    entity_type=PIIType(r.entity_type) if r.entity_type in [e.value for e in PIIType] else PIIType.CUSTOM,
                    text=text[r.start:r.end],
                    start=r.start,
                    end=r.end,
                    score=r.score,
                    recognizer=r.recognition_metadata.get("recognizer_name", "unknown"),
                )
                for r in results
            ]

            return PIIDetectionResult(
                text=text,
                entities=entities,
                has_pii=len(entities) > 0,
                entity_count=len(entities),
            )

        finally:
            # Remove tenant recognizers
            if tenant_id and tenant_id in self._custom_recognizers:
                for recognizer in self._custom_recognizers[tenant_id]:
                    self.analyzer.registry.remove_recognizer(recognizer.name)
```

### PII Redactor Implementation

```python
# services/shared/pii/redactor.py

from dataclasses import dataclass
from enum import Enum
from typing import Optional
from presidio_anonymizer import AnonymizerEngine
from presidio_anonymizer.entities import OperatorConfig
import hashlib

class RedactionMode(Enum):
    """How to handle detected PII."""
    MASK = "mask"           # Replace with <PII_TYPE>
    HASH = "hash"           # Replace with hash
    ENCRYPT = "encrypt"     # Encrypt (reversible)
    REMOVE = "remove"       # Remove entirely
    SYNTHETIC = "synthetic" # Replace with synthetic data

@dataclass
class RedactionResult:
    """Result of PII redaction."""
    original_text: str
    redacted_text: str
    redactions: list[dict]
    has_redactions: bool

class PIIRedactor:
    """Redact PII from text with various strategies."""

    def __init__(self, encryption_key: Optional[bytes] = None):
        self.anonymizer = AnonymizerEngine()
        self.encryption_key = encryption_key

    def redact(
        self,
        text: str,
        entities: list[PIIEntity],
        mode: RedactionMode = RedactionMode.MASK,
        mask_char: str = "*",
        hash_length: int = 8,
    ) -> RedactionResult:
        """
        Redact PII entities from text.

        Args:
            text: Original text
            entities: Detected PII entities
            mode: Redaction strategy
            mask_char: Character for masking
            hash_length: Length of hash replacement

        Returns:
            RedactionResult with redacted text and metadata
        """
        if not entities:
            return RedactionResult(
                original_text=text,
                redacted_text=text,
                redactions=[],
                has_redactions=False,
            )

        # Convert to Presidio format
        analyzer_results = [
            {
                "entity_type": e.entity_type.value,
                "start": e.start,
                "end": e.end,
                "score": e.score,
            }
            for e in entities
        ]

        # Build operators based on mode
        operators = self._build_operators(mode, mask_char, hash_length)

        # Run anonymization
        result = self.anonymizer.anonymize(
            text=text,
            analyzer_results=analyzer_results,
            operators=operators,
        )

        # Build redaction log
        redactions = [
            {
                "entity_type": e.entity_type.value,
                "original": e.text,
                "replacement": self._get_replacement(e, mode, hash_length),
                "start": e.start,
                "end": e.end,
            }
            for e in entities
        ]

        return RedactionResult(
            original_text=text,
            redacted_text=result.text,
            redactions=redactions,
            has_redactions=True,
        )

    def _build_operators(
        self,
        mode: RedactionMode,
        mask_char: str,
        hash_length: int,
    ) -> dict[str, OperatorConfig]:
        """Build Presidio operator configuration."""
        if mode == RedactionMode.MASK:
            return {"DEFAULT": OperatorConfig("replace", {"new_value": f"<{mask_char * 6}>"})}

        elif mode == RedactionMode.HASH:
            return {"DEFAULT": OperatorConfig("hash", {"hash_type": "sha256"})}

        elif mode == RedactionMode.REMOVE:
            return {"DEFAULT": OperatorConfig("replace", {"new_value": ""})}

        elif mode == RedactionMode.ENCRYPT:
            return {"DEFAULT": OperatorConfig("encrypt", {"key": self.encryption_key})}

        elif mode == RedactionMode.SYNTHETIC:
            # Use type-specific synthetic data
            return {
                "EMAIL_ADDRESS": OperatorConfig("replace", {"new_value": "user@example.com"}),
                "PHONE_NUMBER": OperatorConfig("replace", {"new_value": "555-000-0000"}),
                "PERSON": OperatorConfig("replace", {"new_value": "[PERSON]"}),
                "DEFAULT": OperatorConfig("replace", {"new_value": "[REDACTED]"}),
            }

        return {"DEFAULT": OperatorConfig("replace", {"new_value": "[REDACTED]"})}

    def _get_replacement(
        self,
        entity: PIIEntity,
        mode: RedactionMode,
        hash_length: int,
    ) -> str:
        """Get the replacement value for logging."""
        if mode == RedactionMode.MASK:
            return f"<{entity.entity_type.value}>"
        elif mode == RedactionMode.HASH:
            return hashlib.sha256(entity.text.encode()).hexdigest()[:hash_length]
        elif mode == RedactionMode.REMOVE:
            return ""
        else:
            return "[REDACTED]"
```

# services/ingestion/processors/pii_processor.py

from dataclasses import dataclass
from typing import Optional
import structlog
from shared.pii.detector import PIIDetector, PIIDetectionResult
from shared.pii.redactor import PIIRedactor, RedactionMode, RedactionResult

logger = structlog.get_logger()

@dataclass
class PIIProcessingConfig:
    """Configuration for PII processing."""
    enabled: bool = True
    detection_threshold: float = 0.5
    redaction_mode: RedactionMode = RedactionMode.MASK
    store_pii_mapping: bool = False  # For authorized access later
    reject_on_pii: bool = False      # Fail ingestion if PII found
    allowed_pii_types: list[str] = None  # Allow some types through

class PIIProcessor:
    """Process documents for PII during ingestion."""

    def __init__(
        self,
        detector: PIIDetector,
        redactor: PIIRedactor,
        config: PIIProcessingConfig,
    ):
        self.detector = detector
        self.redactor = redactor
        self.config = config

    async def process_document(
        self,
        content: str,
        document_id: str,
        tenant_id: str,
    ) -> tuple[str, dict]:
        """
        Process document content for PII.

        Returns:
            Tuple of (processed_content, pii_metadata)
        """
        if not self.config.enabled:
            return content, {"pii_processed": False}

        # Detect PII
        detection = self.detector.detect(
            text=content,
            tenant_id=tenant_id,
            threshold=self.config.detection_threshold,
        )

        if not detection.has_pii:
            logger.debug(
                "no_pii_detected",
                document_id=document_id,
            )
            return content, {"pii_processed": True, "pii_found": False}

        # Filter allowed PII types
        entities_to_redact = detection.entities
        if self.config.allowed_pii_types:
            entities_to_redact = [
                e for e in detection.entities
                if e.entity_type.value not in self.config.allowed_pii_types
            ]

        # Check if we should reject
        if self.config.reject_on_pii and entities_to_redact:
            logger.warning(
                "document_rejected_pii",
                document_id=document_id,
                pii_count=len(entities_to_redact),
            )
            raise PIIDetectedError(
                f"Document contains {len(entities_to_redact)} PII entities",
                entities=entities_to_redact,
            )

        # Redact PII
        redaction = self.redactor.redact(
            text=content,
            entities=entities_to_redact,
            mode=self.config.redaction_mode,
        )

        logger.info(
            "document_pii_redacted",
            document_id=document_id,
            pii_count=len(entities_to_redact),
            pii_types=[e.entity_type.value for e in entities_to_redact],
        )

        # Build metadata
        metadata = {
            "pii_processed": True,
            "pii_found": True,
            "pii_count": len(entities_to_redact),
            "pii_types": list(set(e.entity_type.value for e in entities_to_redact)),
            "redaction_mode": self.config.redaction_mode.value,
        }

        # Optionally store mapping for authorized access
        if self.config.store_pii_mapping:
            metadata["pii_mapping"] = redaction.redactions

        return redaction.redacted_text, metadata

class PIIDetectedError(Exception):
    """Raised when PII is detected and rejection is configured."""

    def __init__(self, message: str, entities: list):
        super().__init__(message)
        self.entities = entities

# services/orchestrator/security/query_sanitizer.py

from dataclasses import dataclass
from typing import Optional
import structlog
from shared.pii.detector import PIIDetector, PIIType
from shared.pii.redactor import PIIRedactor, RedactionMode

logger = structlog.get_logger()

@dataclass
class QuerySanitizationConfig:
    """Configuration for query PII handling."""
    enabled: bool = True
    detection_threshold: float = 0.6  # Higher threshold for queries
    reject_queries_with_pii: bool = False
    redact_pii_in_logs: bool = True
    alert_on_pii_queries: bool = True
    max_pii_alerts_per_tenant: int = 10  # Per hour

class QuerySanitizer:
    """Sanitize user queries for PII."""

    def __init__(
        self,
        detector: PIIDetector,
        redactor: PIIRedactor,
        config: QuerySanitizationConfig,
    ):
        self.detector = detector
        self.redactor = redactor
        self.config = config
        self._alert_counts: dict[str, int] = {}

    async def sanitize_query(
        self,
        query: str,
        tenant_id: str,
        user_id: Optional[str] = None,
    ) -> tuple[str, str, bool]:
        """
        Sanitize query for PII.

        Returns:
            Tuple of (query_for_processing, query_for_logging, has_pii)
        """
        if not self.config.enabled:
            return query, query, False

        # Detect PII
        detection = self.detector.detect(
            text=query,
            tenant_id=tenant_id,
            threshold=self.config.detection_threshold,
        )

        if not detection.has_pii:
            return query, query, False

        # Log alert (rate limited)
        if self.config.alert_on_pii_queries:
            await self._maybe_alert(tenant_id, user_id, detection)

        # Reject if configured
        if self.config.reject_queries_with_pii:
            raise QueryContainsPIIError(
                "Query contains personal information. Please rephrase without including sensitive data.",
                pii_types=[e.entity_type.value for e in detection.entities],
            )

        # Prepare query for logging
        query_for_logging = query
        if self.config.redact_pii_in_logs:
            redaction = self.redactor.redact(
                text=query,
                entities=detection.entities,
                mode=RedactionMode.MASK,
            )
            query_for_logging = redaction.redacted_text

        # Query for processing stays intact (we still need to search)
        return query, query_for_logging, True

    async def _maybe_alert(
        self,
        tenant_id: str,
        user_id: Optional[str],
        detection,
    ):
        """Send rate-limited alerts for PII in queries."""
        count = self._alert_counts.get(tenant_id, 0)

        if count < self.config.max_pii_alerts_per_tenant:
            logger.warning(
                "pii_in_query",
                tenant_id=tenant_id,
                user_id=user_id,
                pii_types=[e.entity_type.value for e in detection.entities],
                pii_count=len(detection.entities),
            )
            self._alert_counts[tenant_id] = count + 1

class QueryContainsPIIError(Exception):
    """Raised when query contains PII and rejection is configured."""

    def __init__(self, message: str, pii_types: list[str]):
        super().__init__(message)
        self.pii_types = pii_types

# services/orchestrator/security/response_filter.py

from dataclasses import dataclass
from typing import Optional
import structlog
from shared.pii.detector import PIIDetector
from shared.pii.redactor import PIIRedactor, RedactionMode

logger = structlog.get_logger()

@dataclass
class ResponseFilterConfig:
    """Configuration for response PII filtering."""
    enabled: bool = True
    detection_threshold: float = 0.7  # Higher threshold for responses
    redact_pii: bool = True
    log_redactions: bool = True
    fail_on_pii: bool = False  # Fail request if response contains PII

class ResponseFilter:
    """Filter PII from LLM responses."""

    def __init__(
        self,
        detector: PIIDetector,
        redactor: PIIRedactor,
        config: ResponseFilterConfig,
    ):
        self.detector = detector
        self.redactor = redactor
        self.config = config

    async def filter_response(
        self,
        response: str,
        tenant_id: str,
        request_id: Optional[str] = None,
    ) -> tuple[str, dict]:
        """
        Filter PII from LLM response.

        Returns:
            Tuple of (filtered_response, filter_metadata)
        """
        if not self.config.enabled:
            return response, {"pii_filtered": False}

        # Detect PII
        detection = self.detector.detect(
            text=response,
            tenant_id=tenant_id,
            threshold=self.config.detection_threshold,
        )

        if not detection.has_pii:
            return response, {"pii_filtered": True, "pii_found": False}

        # Fail if configured
        if self.config.fail_on_pii:
            logger.error(
                "response_contains_pii",
                request_id=request_id,
                tenant_id=tenant_id,
                pii_count=len(detection.entities),
            )
            raise ResponseContainsPIIError(
                "Generated response contains personal information",
                pii_types=[e.entity_type.value for e in detection.entities],
            )

        # Redact PII
        if self.config.redact_pii:
            redaction = self.redactor.redact(
                text=response,
                entities=detection.entities,
                mode=RedactionMode.MASK,
            )

            if self.config.log_redactions:
                logger.info(
                    "response_pii_redacted",
                    request_id=request_id,
                    tenant_id=tenant_id,
                    pii_count=len(detection.entities),
                    pii_types=[e.entity_type.value for e in detection.entities],
                )

            return redaction.redacted_text, {
                "pii_filtered": True,
                "pii_found": True,
                "pii_count": len(detection.entities),
                "pii_types": list(set(e.entity_type.value for e in detection.entities)),
            }

        return response, {"pii_filtered": True, "pii_found": True}

class ResponseContainsPIIError(Exception):
    """Raised when response contains PII and fail mode is configured."""

    def __init__(self, message: str, pii_types: list[str]):
        super().__init__(message)
        self.pii_types = pii_types

    custom_patterns: list[dict] = None  # Custom regex patterns

    # Ingestion settings
    ingestion_redaction_mode: RedactionMode = RedactionMode.MASK
    ingestion_reject_on_pii: bool = False
    ingestion_allowed_pii_types: list[str] = None

    # Query settings
    query_redact_in_logs: bool = True
    query_reject_with_pii: bool = False

    # Response settings
    response_redact_pii: bool = True
    response_fail_on_pii: bool = False

    # Compliance settings
    data_retention_days: int = 90
    pii_access_audit: bool = True

async def load_tenant_pii_config(
    tenant_id: str,
    db_session,
) -> TenantPIIConfig:
    """Load tenant-specific PII configuration from database."""
    from shared.database.models import TenantSettings

    result = await db_session.execute(
        select(TenantSettings).where(TenantSettings.tenant_id == tenant_id)
    )
    settings = result.scalar_one_or_none()

    if not settings or not settings.pii_config:
        return TenantPIIConfig(tenant_id=tenant_id)

    config = settings.pii_config
    return TenantPIIConfig(
        tenant_id=tenant_id,
        detection_enabled=config.get("detection_enabled", True),
        detection_threshold=config.get("detection_threshold", 0.5),
        custom_patterns=config.get("custom_patterns"),
        ingestion_redaction_mode=RedactionMode(config.get("ingestion_redaction_mode", "mask")),
        ingestion_reject_on_pii=config.get("ingestion_reject_on_pii", False),
        query_redact_in_logs=config.get("query_redact_in_logs", True),
        response_redact_pii=config.get("response_redact_pii", True),
    )

1. **Set up PII detection**
   - Install Presidio and spaCy
   - Download language model
   - Implement PIIDetector class

2. **Implement redaction**
   - Create PIIRedactor with multiple modes
   - Add encryption support for reversible redaction
   - Test with various PII types

3. **Integrate with ingestion**
   - Add PIIProcessor to ingestion pipeline
   - Configure per-tenant settings
   - Store PII metadata

4. **Integrate with orchestrator**
   - Add QuerySanitizer to query flow
   - Add ResponseFilter after LLM generation
   - Handle errors gracefully

5. **Add tenant configuration**
   - Create configuration schema
   - Add API for configuration management
   - Implement configuration loading

6. **Add monitoring**
   - Metrics for PII detection/redaction
   - Alerting for high PII volumes
   - Audit logging for compliance
