# US-10.4.1: Answer Verification Node

> **Initiative:** 4 - Modern RAG Techniques
> **Priority:** P1
> **Effort:** Large (4-5 days)
> **Status:** Draft

## Summary

Add a verification node to the LangGraph workflow that validates generated answers against retrieved context, implementing CRAG-style (Corrective RAG) self-verification.

## Problem Statement

**Current state**: The orchestrator workflow in [workflow/](services/orchestrator/workflow/) generates answers without verification:
- No check if answer is grounded in context
- Hallucinations not detected
- No confidence scoring
- Users may receive unverified information

**Impact**:
- Potential hallucinations in responses
- No quality signal for answers
- Can't filter low-confidence responses
- No basis for feedback correlation

## User Story

**As a** user
**I want** the system to verify answers against retrieved context
**So that** I receive more accurate, grounded responses

## Acceptance Criteria

### AC-1: Verification Node Implementation
- [ ] New `verification` node in LangGraph after `generation`
- [ ] Uses LLM to extract key claims from answer
- [ ] Checks each claim against retrieved context
- [ ] Produces verification score (0-1)

### AC-2: Claim Extraction
- [ ] Extract factual claims from generated answer
- [ ] Limit to meaningful, verifiable claims
- [ ] Configurable max claims (default: 5)

### AC-3: Claim Verification
- [ ] Each claim checked against context
- [ ] Result: `supported`, `partially_supported`, `unsupported`
- [ ] Optional: secondary retrieval for disputed claims

### AC-4: Verification Result
- [ ] Overall score in `RAGState.verification_result`
- [ ] Label: `supported`, `partial`, `unsupported`
- [ ] Configurable per-tenant (opt-in)

### AC-5: Response Adjustment
- [ ] Low-confidence responses get disclaimer
- [ ] Configurable threshold (default: 0.7)
- [ ] Latency budget: max 500ms additional

```python
# services/orchestrator/workflow/verification/claim_extractor.py

from pydantic import BaseModel
from typing import Literal
import structlog

logger = structlog.get_logger(__name__)

class Claim(BaseModel):
    """A factual claim extracted from the answer."""
    text: str
    claim_type: Literal["factual", "numerical", "temporal", "attribution"]
    confidence: float  # Extraction confidence

class ClaimExtractionResult(BaseModel):
    """Result of claim extraction."""
    claims: list[Claim]
    extraction_time_ms: float

CLAIM_EXTRACTION_PROMPT = """
Extract the key factual claims from the following answer.
Focus on verifiable facts, not opinions or general statements.

Answer:
{answer}

Instructions:
1. Identify specific factual assertions
2. Extract up to {max_claims} most important claims
3. Categorize each claim (factual, numerical, temporal, attribution)
4. Return as JSON list

Example output:
[
  {"text": "Python was released in 1991", "claim_type": "temporal"},
  {"text": "The function returns a list of integers", "claim_type": "factual"}
]

Return ONLY the JSON array, no other text.
"""

class ClaimExtractor:
    """Extracts verifiable claims from generated answers."""

    def __init__(self, llm_client, max_claims: int = 5):
        self.llm = llm_client
        self.max_claims = max_claims

    async def extract(self, answer: str) -> ClaimExtractionResult:
        """Extract claims from answer."""
        import time
        start = time.time()

        prompt = CLAIM_EXTRACTION_PROMPT.format(
            answer=answer,
            max_claims=self.max_claims,
        )

        response = await self.llm.complete(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.0,
            max_tokens=500,
        )

        try:
            import json
            claims_data = json.loads(response.content)
            claims = [
                Claim(
                    text=c["text"],
                    claim_type=c.get("claim_type", "factual"),
                    confidence=1.0,
                )
                for c in claims_data
            ]
        except (json.JSONDecodeError, KeyError) as e:
            logger.warning("claim_extraction_parse_error", error=str(e))
            claims = []

        extraction_time = (time.time() - start) * 1000

        return ClaimExtractionResult(
            claims=claims[:self.max_claims],
            extraction_time_ms=extraction_time,
        )
```

### Claim Verification

```python
# services/orchestrator/workflow/verification/claim_verifier.py

from pydantic import BaseModel
from typing import Literal
from enum import Enum

class VerificationStatus(str, Enum):
    SUPPORTED = "supported"
    PARTIALLY_SUPPORTED = "partially_supported"
    UNSUPPORTED = "unsupported"
    UNVERIFIABLE = "unverifiable"

class ClaimVerificationResult(BaseModel):
    """Result of verifying a single claim."""
    claim_text: str
    status: VerificationStatus
    supporting_evidence: str | None = None
    confidence: float  # Verification confidence

CLAIM_VERIFICATION_PROMPT = """
Verify if the following claim is supported by the provided context.

Claim: {claim}

Context:
{context}

Instructions:
1. Check if the context supports the claim
2. Determine if the support is full, partial, or none
3. Quote relevant supporting evidence if found

Respond with JSON:
{{
  "status": "supported" | "partially_supported" | "unsupported" | "unverifiable",
  "evidence": "quoted text from context or null",
  "reasoning": "brief explanation"
}}
"""

class ClaimVerifier:
    """Verifies claims against retrieved context."""

    def __init__(self, llm_client):
        self.llm = llm_client

    async def verify(
        self,
        claim: Claim,
        context: str,
    ) -> ClaimVerificationResult:
        """Verify a single claim against context."""
        prompt = CLAIM_VERIFICATION_PROMPT.format(
            claim=claim.text,
            context=context,
        )

        response = await self.llm.complete(
            messages=[{"role": "user", "content": prompt}],
            temperature=0.0,
            max_tokens=300,
        )

        try:
            import json
            result = json.loads(response.content)
            status = VerificationStatus(result.get("status", "unverifiable"))
            evidence = result.get("evidence")
        except (json.JSONDecodeError, ValueError):
            status = VerificationStatus.UNVERIFIABLE
            evidence = None

        return ClaimVerificationResult(
            claim_text=claim.text,
            status=status,
            supporting_evidence=evidence,
            confidence=0.9 if status != VerificationStatus.UNVERIFIABLE else 0.5,
        )

    async def verify_all(
        self,
        claims: list[Claim],
        context: str,
    ) -> list[ClaimVerificationResult]:
        """Verify all claims in parallel."""
        import asyncio
        tasks = [self.verify(claim, context) for claim in claims]
        return await asyncio.gather(*tasks)
```

### Verification Node

```python
# services/orchestrator/workflow/nodes/verification.py

from dataclasses import dataclass
from orchestrator.workflow.verification.claim_extractor import ClaimExtractor
from orchestrator.workflow.verification.claim_verifier import ClaimVerifier, VerificationStatus
import structlog

logger = structlog.get_logger(__name__)

@dataclass
class VerificationResult:
    """Overall verification result."""
    score: float  # 0-1, proportion of supported claims
    label: str  # supported, partial, unsupported
    claims_total: int
    claims_supported: int
    claims_partial: int
    claims_unsupported: int
    verification_time_ms: float
    skipped: bool = False
    skip_reason: str | None = None

LOW_CONFIDENCE_DISCLAIMER = (
    "\n\n*Note: Some information in this response could not be fully "
    "verified against the available sources. Please verify important "
    "details independently.*"
)

async def verification_node(state: RAGState) -> RAGState:
    """
    Verify generated answer against retrieved context.

    This is an optional node that can be enabled per-tenant.
    It adds latency but improves answer quality assurance.
    """
    import time
    start = time.time()

    # Check if verification is enabled
    if not state.get("enable_verification", False):
        state["verification_result"] = VerificationResult(
            score=1.0,
            label="skipped",
            claims_total=0,
            claims_supported=0,
            claims_partial=0,
            claims_unsupported=0,
            verification_time_ms=0,
            skipped=True,
            skip_reason="verification_disabled",
        )
        return state

    # Check if we have context (no verification for no_retrieval)
    if not state.get("documents") or not state.get("response"):
        state["verification_result"] = VerificationResult(
            score=1.0,
            label="skipped",
            claims_total=0,
            claims_supported=0,
            claims_partial=0,
            claims_unsupported=0,
            verification_time_ms=0,
            skipped=True,
            skip_reason="no_context_or_response",
        )
        return state

    # Build context string from documents
    context = "\n\n".join([
        f"[{i+1}] {doc.content}"
        for i, doc in enumerate(state["documents"][:10])  # Limit context
    ])

    llm_client = state["llm_client"]
    extractor = ClaimExtractor(llm_client, max_claims=5)
    verifier = ClaimVerifier(llm_client)

    # Extract claims
    extraction_result = await extractor.extract(state["response"])
    claims = extraction_result.claims

    if not claims:
        # No claims to verify
        state["verification_result"] = VerificationResult(
            score=1.0,
            label="supported",
            claims_total=0,
            claims_supported=0,
            claims_partial=0,
            claims_unsupported=0,
            verification_time_ms=extraction_result.extraction_time_ms,
            skipped=True,
            skip_reason="no_claims_extracted",
        )
        return state

    # Verify claims
    verification_results = await verifier.verify_all(claims, context)

    # Calculate scores
    supported = sum(1 for r in verification_results if r.status == VerificationStatus.SUPPORTED)
    partial = sum(1 for r in verification_results if r.status == VerificationStatus.PARTIALLY_SUPPORTED)
    unsupported = sum(1 for r in verification_results if r.status == VerificationStatus.UNSUPPORTED)
    total = len(verification_results)

    # Score: full support = 1, partial = 0.5, unsupported = 0
    score = (supported + 0.5 * partial) / total if total > 0 else 1.0

    # Determine label
    if score >= 0.9:
        label = "supported"
    elif score >= 0.5:
        label = "partial"
    else:
        label = "unsupported"

    verification_time = (time.time() - start) * 1000

    state["verification_result"] = VerificationResult(
        score=score,
        label=label,
        claims_total=total,
        claims_supported=supported,
        claims_partial=partial,
        claims_unsupported=unsupported,
        verification_time_ms=verification_time,
    )

    # Add disclaimer if low confidence
    confidence_threshold = state.get("verification_threshold", 0.7)
    if score < confidence_threshold:
        state["response"] += LOW_CONFIDENCE_DISCLAIMER
        logger.info(
            "low_confidence_disclaimer_added",
            score=score,
            threshold=confidence_threshold,
        )

    logger.info(
        "verification_complete",
        score=score,
        label=label,
        claims_total=total,
        claims_supported=supported,
        verification_time_ms=verification_time,
    )

    return state
```
