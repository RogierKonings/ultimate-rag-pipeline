# US-10.1.1: Explicit Indexing State Machine

> **Initiative:** 1 - Multi-Store Indexing & ACL Bulletproofing
> **Priority:** P0
> **Effort:** Medium (2-3 days)
> **Status:** Draft

## Summary

Add explicit tracking of document indexing status across all three stores (Qdrant, OpenSearch, PostgreSQL) to enable visibility into sync state and facilitate automated reconciliation.

## Problem Statement

The current architecture indexes documents to three stores but lacks explicit lifecycle state tracking:

- **Current state**: Documents have only `status` (active/deleted) via `SoftDeleteMixin` in [document.py](services/shared/database/models/document.py)
- **Gap**: No visibility into whether a document's chunks are successfully indexed in Qdrant and OpenSearch
- **Impact**:
  - Operators cannot identify sync issues without manual inspection
  - Failed indexing operations are not easily discoverable
  - No foundation for automated reconciliation (US-10.1.2)

## User Story

**As a** system operator
**I want** to see the indexing status of each document across all stores
**So that** I can identify and resolve sync issues quickly

## Acceptance Criteria

### AC-1: Database Schema Extension
- [ ] Add `qdrant_status` enum field to `Document` model with values: `PENDING`, `OK`, `ERROR`, `STALE`
- [ ] Add `opensearch_status` enum field with same values
- [ ] Add `last_indexed_at` timestamp field (nullable)
- [ ] Add `last_index_error` text field for storing error details (nullable)
- [ ] Add `index_attempts` integer field to track retry count
- [ ] Create database migration with proper indexes

### AC-2: Status Tracking in Ingestion Pipeline
- [ ] `process_document` task updates status to `PENDING` before indexing each store
- [ ] On successful Qdrant indexing: set `qdrant_status = OK`, update `last_indexed_at`
- [ ] On successful OpenSearch indexing: set `opensearch_status = OK`
- [ ] On failure: set status to `ERROR`, store error message, increment `index_attempts`
- [ ] Partial success is handled (e.g., Qdrant succeeds, OpenSearch fails)

### AC-3: API Endpoint for Status Query
- [ ] `GET /api/v1/documents/sync-status` endpoint
- [ ] Supports filtering by: `tenant_id`, `status` (any store), `since` (timestamp)
- [ ] Returns: document count by status, list of problematic documents
- [ ] Pagination support for large result sets

### AC-4: Metrics and Observability
- [ ] Prometheus gauge: `documents_by_index_status{store, status, tenant_id}`
- [ ] Alert rule: documents in ERROR state > threshold for > 5 minutes
- [ ] Structured log entries on status transitions

```python
from enum import Enum
from sqlalchemy import Enum as SQLEnum

class IndexStatus(str, Enum):
    """Indexing status for external stores."""
    PENDING = "pending"    # Indexing not yet attempted or in progress
    OK = "ok"              # Successfully indexed
    ERROR = "error"        # Indexing failed (see last_index_error)
    STALE = "stale"        # Document updated, needs re-indexing

class Document(Base, TimestampMixin, SoftDeleteMixin):
    # ... existing fields ...

    # Indexing status tracking
    qdrant_status: Mapped[IndexStatus] = mapped_column(
        SQLEnum(IndexStatus, name="index_status"),
        default=IndexStatus.PENDING,
        nullable=False,
        index=True,
        comment="Qdrant vector store indexing status"
    )
    opensearch_status: Mapped[IndexStatus] = mapped_column(
        SQLEnum(IndexStatus, name="index_status"),
        default=IndexStatus.PENDING,
        nullable=False,
        index=True,
        comment="OpenSearch keyword index status"
    )
    last_indexed_at: Mapped[datetime | None] = mapped_column(
        DateTime(timezone=True),
        nullable=True,
        comment="Timestamp of last successful indexing to any store"
    )
    last_index_error: Mapped[str | None] = mapped_column(
        Text,
        nullable=True,
        comment="Last indexing error message for debugging"
    )
    index_attempts: Mapped[int] = mapped_column(
        Integer,
        default=0,
        nullable=False,
        comment="Number of indexing attempts (for exponential backoff)"
    )
```

### Ingestion Task Updates

```python
# services/ingestion/tasks/ingest.py - modifications to process_document

async def _index_to_stores(
    self,
    document: Document,
    chunks: list[Chunk],
    embeddings: list[list[float]],
    session: AsyncSession
) -> None:
    """Index chunks to vector and keyword stores with status tracking."""
    from shared.database.models.document import IndexStatus

    # Mark as pending before indexing
    document.qdrant_status = IndexStatus.PENDING
    document.opensearch_status = IndexStatus.PENDING
    document.index_attempts += 1
    await session.commit()

    errors = []

    # Index to Qdrant
    try:
        await self.qdrant_client.upsert_chunks(
            chunks=chunks,
            embeddings=embeddings,
            document_id=document.id,
            tenant_id=document.tenant_id
        )
        document.qdrant_status = IndexStatus.OK
        logger.info(
            "qdrant_indexing_success",
            document_id=str(document.id),
            chunk_count=len(chunks)
        )
    except Exception as e:
        document.qdrant_status = IndexStatus.ERROR
        errors.append(f"Qdrant: {str(e)}")
        logger.error(
            "qdrant_indexing_failed",
            document_id=str(document.id),
            error=str(e)
        )

    # Index to OpenSearch
    try:
        await self.opensearch_client.index_chunks(
            chunks=chunks,
            document_id=document.id,
            tenant_id=document.tenant_id
        )
        document.opensearch_status = IndexStatus.OK
        logger.info(
            "opensearch_indexing_success",
            document_id=str(document.id),
            chunk_count=len(chunks)
        )
    except Exception as e:
        document.opensearch_status = IndexStatus.ERROR
        errors.append(f"OpenSearch: {str(e)}")
        logger.error(
            "opensearch_indexing_failed",
            document_id=str(document.id),
            error=str(e)
        )

    # Update final status
    if errors:
        document.last_index_error = "; ".join(errors)
    else:
        document.last_index_error = None
        document.last_indexed_at = datetime.utcnow()

    await session.commit()
```

```python
# services/ingestion/api/routes.py - new endpoint

from pydantic import BaseModel
from typing import Literal

class SyncStatusQuery(BaseModel):
    tenant_id: str
    status_filter: Literal["all", "ok", "error", "pending", "any_error"] = "all"
    since: datetime | None = None
    limit: int = 100
    offset: int = 0

class DocumentSyncStatus(BaseModel):
    document_id: str
    source_id: str
    qdrant_status: str
    opensearch_status: str
    last_indexed_at: datetime | None
    last_index_error: str | None
    index_attempts: int

class SyncStatusResponse(BaseModel):
    summary: dict[str, int]  # {"ok": 100, "error": 5, "pending": 2}
    documents: list[DocumentSyncStatus]
    total: int
    limit: int
    offset: int

@router.get("/documents/sync-status", response_model=SyncStatusResponse)
async def get_sync_status(
    query: SyncStatusQuery = Depends(),
    session: AsyncSession = Depends(get_session)
) -> SyncStatusResponse:
    """Get document indexing sync status across all stores."""
    from shared.database.models.document import Document, IndexStatus

    # Base query
    stmt = select(Document).where(
        Document.tenant_id == query.tenant_id,
        Document.status == "active"
    )

    # Apply filters
    if query.status_filter == "error":
        stmt = stmt.where(
            or_(
                Document.qdrant_status == IndexStatus.ERROR,
                Document.opensearch_status == IndexStatus.ERROR
            )
        )
    elif query.status_filter == "pending":
        stmt = stmt.where(
            or_(
                Document.qdrant_status == IndexStatus.PENDING,
                Document.opensearch_status == IndexStatus.PENDING
            )
        )
    elif query.status_filter == "any_error":
        stmt = stmt.where(
            or_(
                Document.qdrant_status != IndexStatus.OK,
                Document.opensearch_status != IndexStatus.OK
            )
        )

    if query.since:
        stmt = stmt.where(Document.updated_at >= query.since)

    # Get summary counts
    summary = await _get_status_summary(session, query.tenant_id)

    # Get paginated results
    total = await session.scalar(select(func.count()).select_from(stmt.subquery()))
    stmt = stmt.order_by(Document.updated_at.desc()).limit(query.limit).offset(query.offset)
    result = await session.execute(stmt)
    documents = result.scalars().all()

    return SyncStatusResponse(
        summary=summary,
        documents=[_map_to_sync_status(d) for d in documents],
        total=total,
        limit=query.limit,
        offset=query.offset
    )
```

### Prometheus Metrics

```python
# services/ingestion/observability/metrics.py

from prometheus_client import Gauge

documents_by_index_status = Gauge(
    'documents_by_index_status',
    'Number of documents by indexing status',
    ['store', 'status', 'tenant_id']
)

async def update_index_status_metrics(session: AsyncSession):
    """Update Prometheus gauges with current status counts."""
    from shared.database.models.document import Document, IndexStatus

    # Query aggregated counts
    stmt = select(
        Document.tenant_id,
        Document.qdrant_status,
        Document.opensearch_status,
        func.count(Document.id)
    ).where(
        Document.status == "active"
    ).group_by(
        Document.tenant_id,
        Document.qdrant_status,
        Document.opensearch_status
    )

    result = await session.execute(stmt)

    # Reset and update gauges
    documents_by_index_status.clear()
    for tenant_id, qdrant_status, opensearch_status, count in result:
        documents_by_index_status.labels(
            store='qdrant',
            status=qdrant_status.value,
            tenant_id=tenant_id
        ).set(count)
        documents_by_index_status.labels(
            store='opensearch',
            status=opensearch_status.value,
            tenant_id=tenant_id
        ).set(count)
```
