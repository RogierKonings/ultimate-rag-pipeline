## Additional Feature Suggestions
1. Implement frontend SSE consumption for `/api/v1/query/stream` to reduce time-to-first-token and improve UX for long answers.
2. Add retrieval explain/debug endpoint (weights, stages, component availability, fallbacks) to speed production triage.
3. Add service capability discovery endpoint so frontend can dynamically enable/disable video, reranker, and streaming features safely.
4. Add cache invalidation hooks from ingestion events (document update/delete) into answer cache to avoid stale responses.

## Suggested Execution Order
1. Fix P0 runtime mismatches first: `R1` to `R5`.
2. Consolidate retrieval execution model and complete missing retrieval capabilities: `R6` to `R11`.
3. Close platform consistency and maintainability gaps: `R12` to `R15`.
